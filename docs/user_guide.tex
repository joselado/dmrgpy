This guide explains how to compute physical quantities with DMRGPY. For each
capability it gives the quantity, its formula, the code and the keywords that
matter. It does not explain how the code works inside; for that, see
\texttt{docs/documentation.\allowbreak{}md}.

Every chain class (\texttt{Spin\_\allowbreak{}Chain}, \texttt{Fermionic\_\allowbreak{}Chain}, \texttt{Bosonic\_\allowbreak{}Chain}, \ldots) has
the same methods. Most calls accept \texttt{mode="DMRG"} or \texttt{mode="ED"}, so a DMRG
result on a small chain can be checked against exact diagonalization.

\section{Physical models and Hilbert spaces}

Every model is a chain of \(n\) local Hilbert spaces,
\(\mathcal H=\bigotimes_{i=1}^n\mathcal H_i\). The chain class fixes the local
space and gives lists of local operators, indexed by site. The Hamiltonian
and the observables are then built from these operators (section 2).

The spin operators of a spinful fermion are
\(S^z_i=\tfrac12(n_{i\uparrow}-n_{i\downarrow})\),
\(S^+_i=c^\dagger_{i\uparrow}c_{i\downarrow}\), and the onsite pairing is
\(\Delta_i=\tfrac12c_{i\uparrow}c_{i\downarrow}\). In the mixed chains, an
operator that does not exist on a site (for example \texttt{Cup} on a spin site)
is zero.

\texttt{Spinful\_\allowbreak{}Fermionic\_\allowbreak{}Chain} stores each orbital as two spinless sites, and
\texttt{Spinful\_\allowbreak{}Fermionic\_\allowbreak{}Chain\_\allowbreak{}Native} as one 4-state site. The physics and the
sign conventions are the same. In practice the native class is not faster,
so \texttt{Spinful\_\allowbreak{}Fermionic\_\allowbreak{}Chain} is the default choice.
\texttt{Mixed\_\allowbreak{}Spin\_\allowbreak{}Fermion\_\allowbreak{}Chain} is for models with a true local moment next to
conduction electrons, such as the Kondo lattice
(\texttt{examples/fermion\_\allowbreak{}models/mixed\_\allowbreak{}spin\_\allowbreak{}fermion\_\allowbreak{}chain}).

Some classes do not run on every backend:

\begin{itemize}
\tightlist
\item
  \texttt{Spinful\_\allowbreak{}Fermionic\_\allowbreak{}Chain\_\allowbreak{}Native}, \texttt{Mixed\_\allowbreak{}Spin\_\allowbreak{}Fermion\_\allowbreak{}Chain} and
  \texttt{SpinBoson\_\allowbreak{}Chain}: \texttt{itensor\_\allowbreak{}version=3} and \texttt{"python"} only.
\item
  \texttt{SpinBoson\_\allowbreak{}Chain}: no \texttt{mode="ED"}. Use \texttt{Bosonic\_\allowbreak{}Chain} for a purely
  bosonic model.
\item
  \texttt{Bosonic\_\allowbreak{}Chain} with \texttt{maxnb} different from 4: not on
  \texttt{itensor\_\allowbreak{}version=2}, it raises an error.
\end{itemize}

Every constructor takes \texttt{itensor\_\allowbreak{}version=} and the chain settings as
keywords. A keyword has the same effect as an assignment after
construction, so

\begin{lstlisting}
from dmrgpy import spinchain
sc = spinchain.Spin_Chain(["S=1/2"]*20, maxm=60, nsweeps=20)
\end{lstlisting}

is the same as setting \texttt{sc.\allowbreak{}maxm\ =\ 60} and \texttt{sc.\allowbreak{}nsweeps\ =\ 20} afterwards. A
keyword that is not a setting (for example \texttt{hubbard=} or \texttt{hamiltonian=})
raises an error.

\section{Building a Hamiltonian and observables}

A Hamiltonian or an observable is written as its operator expression, with
the operator lists of section 1. For the spin-1/2 Heisenberg chain,

\[H=J\sum_{i=1}^{n-1}\mathbf S_i\cdot\mathbf S_{i+1}
=J\sum_{i=1}^{n-1}\left(S_i^xS_{i+1}^x+S_i^yS_{i+1}^y+S_i^zS_{i+1}^z\right),\]

\begin{lstlisting}
from dmrgpy import spinchain
n = 30
sc = spinchain.Spin_Chain(["S=1/2" for i in range(n)])
h = 0
for i in range(n-1):
    h = h + sc.Sx[i]*sc.Sx[i+1] + sc.Sy[i]*sc.Sy[i+1] + sc.Sz[i]*sc.Sz[i+1]
sc.set_hamiltonian(h)
\end{lstlisting}

Any sum of products of local operators is allowed, with any range and
complex coefficients. This covers single-ion anisotropy \(D(S^z_i)^2\),
Dzyaloshinskii-Moriya terms \(\mathbf D\cdot(\mathbf S_i\times\mathbf S_{i+1})\),
biquadratic exchange \((\mathbf S_i\cdot\mathbf S_{i+1})^2\), hopping
\(t\sum_i(c_i^\dagger c_{i+1}+\mathrm{h.c.})\), the Hubbard term
\(U\sum_in_{i\uparrow}n_{i\downarrow}\), and so on. Section 16 gives complete
models. \texttt{h.\allowbreak{}get\_\allowbreak{}dagger()} returns \(h^\dagger\), so \texttt{h\ +\ h.\allowbreak{}get\_\allowbreak{}dagger()} adds
the Hermitian conjugate. It is best to write \(H\) in units where its largest
coefficient is of order 1: a few routes, such as real-time evolution, use
absolute thresholds.

\textbf{Shortcuts on fermionic chains.} These methods take a function \texttt{f(i,j)}
of two sites and add the whole family of terms:

\begin{itemize}
\tightlist
\item
  \texttt{fc.\allowbreak{}set\_\allowbreak{}hoppings(f)}: \(\sum_{ij}f(i,j)\,c_i^\dagger c_j\). On a
  \texttt{Spinful\_\allowbreak{}Fermionic\_\allowbreak{}Chain} the indices run over the spinless sites
  (up and down alternate).
\item
  \texttt{fc.\allowbreak{}set\_\allowbreak{}hoppings\_\allowbreak{}spinful(f)}: the same hopping for both spins, with \texttt{f}
  indexed by orbital. Spinful chains.
\item
  \texttt{fc.\allowbreak{}set\_\allowbreak{}hubbard(f)}: \(\sum_{ij}f(i,j)\,n_in_j\), with
  \(n_i=n_{i\uparrow}+n_{i\downarrow}\) on spinful chains. Note that the
  \(i=j\) term is \(f(i,i)\,n_i^2=f(i,i)(n_i+2n_{i\uparrow}n_{i\downarrow})\).
\end{itemize}

\begin{lstlisting}
from dmrgpy import fermionchain
fc = fermionchain.Fermionic_Chain(4)
fc.set_hoppings(lambda i,j: 1.0 if abs(i-j)==1 else 0.0)
fc.set_hubbard(lambda i,j: 2.0 if abs(i-j)==1 else 0.0)
\end{lstlisting}

\textbf{Operators.} On an operator \texttt{A}, \texttt{A.\allowbreak{}simplify()} collects equal terms,
and \texttt{A.\allowbreak{}is\_\allowbreak{}hermitian()}, \texttt{A.\allowbreak{}is\_\allowbreak{}antihermitian()} and \texttt{A.\allowbreak{}is\_\allowbreak{}zero()} answer by
reading the terms. A \texttt{True} answer is exact. A \texttt{False} answer can be wrong
when the property depends on an identity of the local space, such as
\(S^xS^x=1/4\) for spin 1/2. \texttt{sc.\allowbreak{}is\_\allowbreak{}hermitian(A)} does not have this
limitation, since it also checks numerically on the chain.

\texttt{sc.\allowbreak{}toMPO(A)} builds the matrix product operator of \texttt{A} once. Two such
operators can be added, subtracted and multiplied by numbers
(\texttt{A\ +\ 2*B\ -\ A}). Not available on \texttt{"julia\_\allowbreak{}live"}. To combine Hamiltonians,
it is simpler to sum the operator expressions before calling
\texttt{set\_\allowbreak{}hamiltonian}.

\texttt{mode="ED"} on a small chain.

\section{Ground-state properties}

In this section we compute the ground state of a chain and measure it. All
the examples use a spin-1/2 Heisenberg chain:

\begin{lstlisting}
from dmrgpy import spinchain
n = 20
sc = spinchain.Spin_Chain(["S=1/2" for i in range(n)])
h = sum(sc.Sx[i]*sc.Sx[i+1] + sc.Sy[i]*sc.Sy[i+1] + sc.Sz[i]*sc.Sz[i+1]
        for i in range(n-1))
sc.set_hamiltonian(h)
\end{lstlisting}

\textbf{Ground-state energy.} The ground state is the state with the lowest
energy,

\[E_0=\min_{|\psi\rangle}\frac{\langle\psi|H|\psi\rangle}{\langle\psi|\psi\rangle}.\]

\begin{lstlisting}
e0 = sc.gs_energy()   # E0
wf = sc.get_gs()      # the ground state |GS> as an MPS
\end{lstlisting}

DMRG finds this minimum within matrix product states of bond dimension
\texttt{sc.\allowbreak{}maxm}. The result is exact when \texttt{maxm} is large enough, and an upper
bound on \(E_0\) otherwise. The keywords that control accuracy are:

\begin{itemize}
\tightlist
\item
  \texttt{sc.\allowbreak{}maxm}: the bond dimension. Increase it until \(E_0\) stops changing.
  Gapped chains need a small \texttt{maxm}; critical chains and wide ladders need
  a large one.
\item
  \texttt{sc.\allowbreak{}nsweeps}: the number of DMRG sweeps.
\item
  \texttt{gs\_\allowbreak{}energy(maxde=1e-4)}: doubles \texttt{maxm} until the energy fluctuation per
  site (see below) is smaller than \texttt{maxde}.
\item
  \texttt{mode="ED"}: exact diagonalization, for small chains and for checking
  DMRG.
\end{itemize}

The chain stores the ground state. A second call to \texttt{gs\_\allowbreak{}energy()} returns
it without solving again.

\textbf{Expectation values.} For any operator \(O\) built from the chain
operators, as \(H\) is,

\[\langle O\rangle=\langle\mathrm{GS}|O|\mathrm{GS}\rangle,\qquad
\langle O^n\rangle=\langle\mathrm{GS}|O^n|\mathrm{GS}\rangle.\]

\begin{lstlisting}
mz = [sc.vev(sc.Sz[i]).real for i in range(n)]   # magnetization profile
e2 = sc.vev(h, npow=2)                           # <H^2>
\end{lstlisting}

Common profiles have their own methods, each returning one value per site:

\begin{itemize}
\tightlist
\item
  \texttt{get\_\allowbreak{}density()}: the occupation \(\langle n_i\rangle\), summed over spin.
  Fermionic chains.
\item
  \texttt{get\_\allowbreak{}density\_\allowbreak{}fluctuation()}: \(\langle n_i^2\rangle-\langle n_i\rangle^2\).
  Fermionic chains.
\item
  \texttt{get\_\allowbreak{}onsite\_\allowbreak{}pairing()}: \(\langle c_{i\uparrow}c_{i\downarrow}\rangle\).
  Spinful fermionic chains.
\item
  \texttt{get\_\allowbreak{}magnetization()}: \(\langle S^x_i\rangle\), \(\langle S^y_i\rangle\),
  \(\langle S^z_i\rangle\) as a \(3\times n\) array. Spin and spinful fermionic
  chains.
\end{itemize}

\textbf{Static correlators.} A two-point correlator is the expectation value of
a product of two operators:

\begin{lstlisting}
czz = [sc.vev(sc.Sz[0]*sc.Sz[i]).real for i in range(n)]       # <Sz_0 Sz_i>
cdc = fc.vev(fc.Cdag[0]*fc.C[5])   # <c^dag_0 c_5> on a fermionic chain fc
\end{lstlisting}

The equal-time structure factor is its Fourier transform,
\(S(q)=\sum_{i,j}e^{iq(i-j)}\langle O_iO_j\rangle\). This is the
quantity measured by neutron or X-ray diffraction, and it is the
frequency integral of the dynamical correlators of section 6.

\textbf{Energy fluctuation.} The energy variance tells us how close the state is
to an eigenstate of \(H\):

\[\delta E=\sqrt{\langle H^2\rangle-\langle H\rangle^2}.\]

\begin{lstlisting}
de = sc.gs_energy_fluctuation()
\end{lstlisting}

For an exact eigenstate \(\delta E=0\). In DMRG, \(\delta E\) comes from the
truncation of the bond dimension, so it is a direct check of \texttt{maxm}. It is
a stricter check than the energy itself: roughly, the energy error is of
order \(\delta E^2\), while the error of other observables is of order
\(\delta E\).

\textbf{Fixed particle number or fixed magnetization.} Without any constraint,
DMRG returns the global ground state, at whatever particle number or total
\(S^z\) it has. When \(H\) conserves a charge \(Q\), we can instead ask for the
ground state of one sector,

\[E_0(q)=\min_{\hat Q|\psi\rangle=q|\psi\rangle}
\frac{\langle\psi|H|\psi\rangle}{\langle\psi|\psi\rangle}.\]

Here \texttt{fc} is a \texttt{Fermionic\_\allowbreak{}Chain} and \texttt{hc} a \texttt{Spinful\_\allowbreak{}Fermionic\_\allowbreak{}Chain\_\allowbreak{}Native}.

\begin{lstlisting}
fc.set_conserved_sector(Nf=6)          # exactly 6 fermions
sc.set_conserved_sector(Sz=0)          # total Sz = 0
hc.set_conserved_sector(Nf=8, Sz=0)    # Hubbard chain: both
fc.set_conserved_sector()              # back to the full Hilbert space
\end{lstlisting}

\texttt{Sz} is given in units of \(1/2\), so \texttt{Sz=2} means \(S^z_\mathrm{tot}=1\).
The available charges are \texttt{Nf} for fermions, \texttt{Sz} for spins, both for the
native Hubbard chain, and \texttt{Nb} for bosons. Parafermion chains have none.

With sectors we compute the addition spectrum \(E_0(N)\), the charge gap
\(E_0(N+1)+E_0(N-1)-2E_0(N)\), and the magnetization curve, each point being
a true ground state of its own sector. The same calls work with
\texttt{mode="ED"}. On large chains a sector is also faster, by about 4 times at
\(n=60\).

Inside a sector, every operator must conserve the charge. An operator that
changes it, for example \(c_i\) at fixed \(N_f\) or \(S^x_i\) at fixed \(S^z\),
raises an error. To apply such an operator to the sector ground state,
first convert the state to an ordinary MPS:

\begin{lstlisting}
fc.set_conserved_sector(Nf=6)
fc.gs_energy()
fc.promote_to_dense()                    # same state, no sector
wf = fc.applyoperator(fc.C[3], fc.wf0)   # c_3 |GS_N>, now with 5 fermions
\end{lstlisting}

Two ground states with \(N\) and \(N-1\) fermions, both converted this way, can
be compared directly. This gives for example the photoemission weight
\(Z_i=|\langle\mathrm{GS}_{N-1}|c_i|\mathrm{GS}_N\rangle|^2\)
(see \texttt{examples/groundstate/sector\_\allowbreak{}promotion\_\allowbreak{}to\_\allowbreak{}dense}).

Sectors work on \texttt{itensor\_\allowbreak{}version=3}, \texttt{itensor\_\allowbreak{}version="python"} and
\texttt{mode="ED"}. They are not available on \texttt{itensor\_\allowbreak{}version=2}, on
\texttt{"julia\_\allowbreak{}live"}, with METTS and for infinite chains; these raise an error.

\section{Excited states and energy gaps}

In this section we compute the low-energy spectrum: excited states, gaps,
non-Hermitian and generalized eigenproblems, and effective Hamiltonians of
a low-energy manifold. Here \texttt{sc} is the Heisenberg chain of section 3.

\textbf{Low-lying spectrum.} The lowest eigenvalues \(E_0\le E_1\le\dots\) of \(H\)
and the gap \(\Delta=E_1-E_0\) are

\begin{lstlisting}
es = sc.get_excited(n=4)                 # [E0, E1, E2, E3]
gap = sc.get_gap()                       # E1 - E0
es, ws = sc.get_excited_states(n=4)      # energies and states
\end{lstlisting}

The list has one entry per eigenstate, so a degenerate level appears once
for each state of the multiplet. If the ground state is degenerate,
\texttt{get\_\allowbreak{}gap()} is zero, and we must ask for enough states to reach the first
excited level. When DMRG splits a multiplet slightly, identify the states
by a quantum number (for example \(\langle\mathbf S^2\rangle\)) and not by
their position in the list.

DMRG finds each excited state as the ground state of \(H\) plus a penalty
on the states already found. This search can converge to a wrong state.
When the energy variance of a state is much larger than that of the ground
state, a warning is printed, and the state should be checked with more
sweeps, a larger \texttt{maxm} or \texttt{mode="ED"} on a smaller chain. The keywords are:

\begin{itemize}
\tightlist
\item
  \texttt{n}: the number of states.
\item
  \texttt{scale}: the weight of the penalty, in units of the bandwidth of \(H\)
  (default 10).
\item
  \texttt{purify=True} (default, \texttt{get\_\allowbreak{}excited\_\allowbreak{}states}): diagonalizes \(H\) again in
  the space of the states found, which separates nearly degenerate states.
\end{itemize}

For example, an open spin-1 Heisenberg chain has four low states from the
two spin-1/2 edge modes (a singlet and a triplet), and the Haldane gap is
the gap to the next state:

\begin{lstlisting}
es = s1.get_excited(n=6)    # s1: an open spin-1 Heisenberg chain
haldane_gap = es[4] - es[0]
\end{lstlisting}

\textbf{Gap to another particle number.} For a conserved charge \(A\), for
example the particle number \(N=\sum_in_i\), \texttt{get\_\allowbreak{}charge\_\allowbreak{}gap(d=.\allowbreak{}.\allowbreak{}.\allowbreak{})} gives
the energy to change \(\langle A\rangle\) by \(d\) from its ground-state value
\(A_0\). It solves

\[H_\lambda=H+\lambda\big(A-A_0-d\big)^2,\]

increasing \(\lambda\) until the constraint holds, and returns
\(\Delta(d)=E_0(A_0+d)-E_0(A_0)\).

\begin{lstlisting}
gap2 = fc.get_charge_gap(d=2)    # fc: a fermionic chain; add two particles
\end{lstlisting}

\texttt{d=2} is the cost of adding a pair, and \texttt{d=-2} of removing one.
\texttt{Fermionic\_\allowbreak{}Chain}, \texttt{Spinful\_\allowbreak{}Fermionic\_\allowbreak{}Chain} and the native spinful chain
have this method. The conserved sectors of section 3 give the same energies
directly, \(E_0(N)\) for each \(N\).

\textbf{Non-Hermitian Hamiltonians.} When \(H\neq H^\dagger\) (gain and loss,
complex or non-reciprocal hopping), the ground state is the eigenvalue with
the smallest real part. Eigenstates come in left and right pairs,

\[H|\psi_R\rangle=E|\psi_R\rangle,\qquad
H^\dagger|\psi_L\rangle=E^*|\psi_L\rangle,\qquad
\langle\psi_L|\psi_R\rangle=1.\]

\texttt{gs\_\allowbreak{}energy()} detects a non-Hermitian \(H\) and uses non-Hermitian DMRG
(NH-DMRG). Here \texttt{fc} is a fermionic chain with a non-Hermitian Hamiltonian,
for example a staggered imaginary potential \(i\gamma(-1)^in_i\):

\begin{lstlisting}
e, psil, psir = fc.nhdmrg()     # E, left and right eigenvectors
e = fc.gs_energy()              # the same E; stores psir as the ground state
\end{lstlisting}

The energy is not a variational bound, so the result is checked with the
residuals \(\lVert H|\psi_R\rangle-E|\psi_R\rangle\rVert\) and
\(\lVert H^\dagger|\psi_L\rangle-E^*|\psi_L\rangle\rVert\). The keywords are:

\begin{itemize}
\tightlist
\item
  \texttt{tol}: the largest relative residual accepted (default \texttt{1e-4}).
\item
  \texttt{ntries}: how many times to restart from a random state when the residual
  is too large (default 5).
\end{itemize}

Excited states of a non-Hermitian \(H\) come from \texttt{get\_\allowbreak{}excited\_\allowbreak{}states(n)} and
\texttt{get\_\allowbreak{}excited(n)}, which use an Arnoldi method on matrix product states. It
is less accurate than NH-DMRG, so check it against \texttt{mode="ED"} on a small
chain (\texttt{examples/non\_\allowbreak{}hermitian/nhdmrg\_\allowbreak{}VS\_\allowbreak{}ED\_\allowbreak{}VS\_\allowbreak{}arnoldi}). NH-DMRG works on
\texttt{itensor\_\allowbreak{}version=2}, \texttt{3}, \texttt{"python"} and \texttt{"julia\_\allowbreak{}live"}.

\textbf{Generalized eigenvalue problem.} For a Hermitian positive definite
operator \(A\),

\[H|\psi\rangle=\lambda A|\psi\rangle .\]

\begin{lstlisting}
A = fc.Id + 0.5*sum(fc.N)           # for example
lam = fc.gs_energy_generalized(A)   # smallest lambda
\end{lstlisting}

DMRG solves this directly, with no inverse of \(A\). A non-Hermitian \(H\) is
also accepted, and then \(\lambda\) is the complex eigenvalue with the
smallest real part. Not available on \texttt{itensor\_\allowbreak{}version=2}, it raises an
error.

After this call the chain stores the generalized eigenstate as its ground
state, and \texttt{fc.\allowbreak{}e0} is its energy
\(\langle\psi|H|\psi\rangle/\langle\psi|\psi\rangle\) (with left and right
states for a non-Hermitian \(H\)), while \(\lambda\) is in
\texttt{fc.\allowbreak{}lam\_\allowbreak{}generalized}. Every later calculation (excited states,
correlators) uses this state. So call it last, or call \texttt{fc.\allowbreak{}restart()} and
\texttt{fc.\allowbreak{}gs\_\allowbreak{}energy()} to get back the true ground state.

\textbf{Effective low-energy Hamiltonians.} Take the \(n\) lowest eigenstates and
the projector \(P=\sum_{k<n}|\psi_k\rangle\langle\psi_k|\) on them. We write
the projected Hamiltonian as a combination of projected operators \(O_a\),

\[PHP\simeq\sum_aJ_a\,PO_aP,\]

and fit the couplings \(J_a\) by least squares. This gives, for example, the
spin exchange of a Hubbard model at strong coupling,
\(J\approx4t^2/U\):

\begin{lstlisting}
# fc: a Spinful_Fermionic_Chain(2) Hubbard dimer
J = fc.get_heff(operators=[fc.Sx[0]*fc.Sx[1], fc.Sy[0]*fc.Sy[1],
                           fc.Sz[0]*fc.Sz[1]], n=4)    # one J per operator

from dmrgpy import effectivehamiltonian
coef = effectivehamiltonian.get_effective_hamiltonian_couplings(fc, n=4)
latex = effectivehamiltonian.get_effective_hamiltonian(fc, n=4)
\end{lstlisting}

\texttt{get\_\allowbreak{}heff} fits the operators given. \texttt{get\_\allowbreak{}effective\_\allowbreak{}hamiltonian\_\allowbreak{}couplings}
fits all products \(S^\alpha_iS^\beta_j\) of the chain spin operators and
returns a dictionary, and \texttt{get\_\allowbreak{}effective\_\allowbreak{}hamiltonian} returns the same fit
as a LaTeX string. The keywords are:

\begin{itemize}
\tightlist
\item
  \texttt{n}: the number of states in the manifold. It must not cut a degenerate
  multiplet, otherwise the fit is not meaningful and it raises an error.
\item
  \texttt{operators}: the operators of the fit. They must be linearly independent
  in the manifold, otherwise the couplings are not unique and it raises an
  error.
\item
  \texttt{tol}: couplings smaller than this are set to zero.
\item
  \texttt{method}: \texttt{"single"} (default) fits \(PO_aP\,PO_bP\), and \texttt{"full"} fits
  \(P\,O_aO_b\,P\). They differ when the manifold is not closed under \(O_a\).
\item
  \texttt{mode="ED"}: exact eigenstates, for small systems.
\end{itemize}

See \texttt{examples/groundstate/effective\_\allowbreak{}hamiltonian}, which fits the twisted
exchange of a Hubbard dimer with a Peierls phase.

\section{Entanglement and quantum information}

In this section we measure the entanglement of a state. Here \texttt{wf} is a
ground state, for example \texttt{wf\ =\ sc.\allowbreak{}get\_\allowbreak{}gs()} for the Heisenberg chain of
section 3.

\textbf{Entanglement entropy of a cut.} We cut the chain between sites \(i\) and
\(i+1\). The Schmidt decomposition of the state is
\(|\psi\rangle=\sum_\alpha\lambda_\alpha|\alpha\rangle_L|\alpha\rangle_R\),
and the von Neumann entropy of the left part is

\[S_i=-\sum_\alpha\lambda_\alpha^2\log\lambda_\alpha^2
=-\mathrm{Tr}\,\rho_L\log\rho_L,\qquad
\rho_L=\mathrm{Tr}_R|\psi\rangle\langle\psi|.\]

\begin{lstlisting}
s = wf.get_bond_entropy(i, i+1)     # cut between sites i and i+1
s = wf.get_entropy(b)               # the same, cut between sites b-1 and b
\end{lstlisting}

In a gapped chain \(S_i\) saturates with the size of the block, and in a
critical chain it grows as \(\log\ell\). It also tells us the bond dimension
we need, roughly \(\chi\gtrsim e^{S}\). The bond entropy needs an MPS, so it
is not available with \texttt{mode="ED"}.

\textbf{Entropy of one site or two sites.} \texttt{wf.\allowbreak{}get\_\allowbreak{}site\_\allowbreak{}entropy(i)} and
\texttt{wf.\allowbreak{}get\_\allowbreak{}pair\_\allowbreak{}entropy(i,\ j)} give the entropy of the reduced density matrix
of site \(i\), or of the two sites \(i\) and \(j\) (not necessarily neighbors),
with the rest of the chain. They are available for spin-1/2 chains and
spinless fermionic chains. With \texttt{mode="ED"}, call them on the chain:
\texttt{sc.\allowbreak{}get\_\allowbreak{}site\_\allowbreak{}entropy(wf,\ i)}, \texttt{sc.\allowbreak{}get\_\allowbreak{}pair\_\allowbreak{}entropy(wf,\ i,\ j)}.

\textbf{Mutual information.} For two sites \(i\) and \(j\),

\[I(i,j)=S_i+S_j-S_{ij},\]

\begin{lstlisting}
mi = wf.get_mutual_information(i, j)
\end{lstlisting}

\(I(i,j)\) measures all the correlations, classical and quantum, between the
two sites, so it shows which sites are coupled in the state even when no
term of \(H\) couples them. Same availability as the site entropy.

\textbf{Central charge.} For a critical open chain of length \(L\), the entropy
of a cut at position \(\ell\) follows the Calabrese-Cardy formula,

\[S(\ell)=\frac c6\log\!\left[\frac{2L}{\pi}\sin\frac{\pi\ell}{L}\right]+\text{const}.\]

The central charge \(c\) identifies the conformal field theory, for example
\(c=1/2\) for the critical Ising chain and \(c=1\) for the XX and Heisenberg
chains. \texttt{get\_\allowbreak{}CFT\_\allowbreak{}central\_\allowbreak{}charge()} fits this formula to the entropy of
every bond:

\begin{lstlisting}
c = wf.get_CFT_central_charge()
\end{lstlisting}

On an open chain the entropy also has a term that alternates between even
and odd bonds, and the fit does not remove it. So the result converges
slowly with \(L\): for the spin-1/2 XX chain it gives about 0.54 at \(L=20\)
and 0.74 at \(L=40\). Use long chains, or fit the bond entropies yourself
with only even (or only odd) \(\ell\).

\textbf{Single-particle correlation matrix.} For fermions, the correlation
matrix is

\[C_{ij}=\langle c_i^\dagger c_j\rangle .\]

Its eigenvalues \(n_\alpha\in[0,1]\) are the occupations of the natural
orbitals. For a single Slater determinant every \(n_\alpha\) is 0 or 1.
Interactions move them away from 0 and 1, and the correlation entropy
measures how far the state is from a single Slater determinant:

\[S=-\sum_\alpha\Big[n_\alpha\log n_\alpha+(1-n_\alpha)\log(1-n_\alpha)\Big].\]

Here \texttt{fc} is a fermionic chain with its Hamiltonian set.

\begin{lstlisting}
cm = fc.get_correlation_matrix()          # C_ij
na = fc.get_correlation_eigenvalues()     # n_alpha
s = fc.get_correlation_entropy()          # S
orb = fc.get_correlated_orbitals()        # |orbital|^2, most correlated first
rho = fc.get_correlated_density(n=2)      # weight of the 2 most correlated orbitals
sd = fc.get_gs().get_correlation_entropy_density()   # S resolved by site
\end{lstlisting}

The most correlated orbitals are those with \(n_\alpha\) closest to \(1/2\).
The keywords are:

\begin{itemize}
\tightlist
\item
  \texttt{T}: temperature of \texttt{get\_\allowbreak{}correlation\_\allowbreak{}matrix} (default 0). Finite \(T\) is
  computed with exact eigenstates, for small chains.
\item
  \texttt{dmmode}: how \(C_{ij}\) is computed (\texttt{"fast"}, \texttt{"full"}, \texttt{"explicit"},
  \texttt{"simple"}). The default chooses the fastest one for the state.
  \texttt{"explicit"} works on every backend.
\end{itemize}

\textbf{Two-particle correlators.} The four-point tensor
\(\langle c_i^\dagger c_jc_k^\dagger c_l\rangle\) for all \(i,j,k,l\) is

\begin{lstlisting}
t = fc.get_gs().get_four_correlation_tensor()   # shape (n, n, n, n)
\end{lstlisting}

The keyword \texttt{ctmode} chooses the method (\texttt{"batched"}, \texttt{"sweep"}, \texttt{"fold"},
\texttt{"full"}, \texttt{"explicit"}). The default chooses the fastest one for the
backend, and \texttt{"explicit"} works on every backend.
The two-particle density matrix
\(\langle c_i^\dagger c_j^\dagger c_lc_k\rangle\), with the pairs \(i<j\) and
\(k<l\) as row and column, is

\begin{lstlisting}
from dmrgpy.entropytk.correlationentropy import get_highorder_correlation_matrix
d2 = get_highorder_correlation_matrix(fc)
\end{lstlisting}

\section{Dynamical (frequency-dependent) correlators}

In this section we compute zero-temperature dynamical correlators: the
dynamical spin structure factor, the single-particle spectral function, and
the correlator of any pair of operators \((A,B)\).

\textbf{The quantity.} For a pair \((A,B)\), \texttt{get\_\allowbreak{}dynamical\_\allowbreak{}correlator} returns the
Lehmann spectral density

\[S_{AB}(\omega)=\sum_n M_n\,\frac{\delta/\pi}{(\omega-\Delta_n)^2+\delta^2}
=\frac{i}{2\pi}\Big[G^R_{AB}(\omega)-G^A_{AB}(\omega)\Big],\]

with \(M_n=\langle\mathrm{GS}|A|n\rangle\langle n|B|\mathrm{GS}\rangle\),
\(\Delta_n=E_n-E_0\), and the resolvents
\(G^{R/A}_{AB}(\omega)=\langle\mathrm{GS}|A\,(\omega+E_0\pm i\delta-H)^{-1}B|\mathrm{GS}\rangle\).
The frequency \(\omega\) is measured from the ground-state energy \(E_0\), and
\(\delta\) is the broadening. When every \(M_n\) is real, \(S_{AB}\) is real and
equal to \(-\frac1\pi\mathrm{Im}\,G^R_{AB}(\omega)\). This is always the case
for a Hermitian pair \(A=B^\dagger\), where \(S_{AB}\ge0\), and also for real
operators on a real Hamiltonian. In general \(M_n\) is complex, so the
returned array is complex. A converged calculation satisfies the sum rule

\[\int d\omega\,S_{AB}(\omega)=\langle\mathrm{GS}|AB|\mathrm{GS}\rangle,\]

which is a simple check of a calculation. For EX and SECTOR (below) the
missing weight is the part of the spectrum outside the states kept. Here \(|\mathrm{GS}\rangle\) is the
ground state of the chain, or the state set with \texttt{set\_\allowbreak{}gs()}.

All the examples use the Heisenberg chain \texttt{sc} of section 3.

\begin{lstlisting}
import numpy as np
es = np.linspace(-1, 4, 300)                      # frequencies
(x, y) = sc.get_dynamical_correlator(name=(sc.Sz[0], sc.Sz[0]),
                                     es=es, delta=0.1)
print(np.sum(y.real)*(x[1]-x[0]))                 # sum rule: <Sz_0 Sz_0> = 0.25
\end{lstlisting}

The keywords that every method shares are:

\begin{itemize}
\tightlist
\item
  \texttt{name=(A,\ B)}: the operator pair, built from the chain operators. A
  string with two sites also works, \texttt{name="ZZ",\ i=0,\ j=3}, as do \texttt{"XX"},
  \texttt{"YY"}, \texttt{"+-"}, \texttt{"cdc"} and \texttt{"densitydensity"}.
\item
  \texttt{es}: the frequency grid.
\item
  \texttt{delta}: the broadening. A pole becomes a line of full width \(2\delta\).
\item
  \texttt{submode}: the method, see ``Choosing a method'' below. The default is
  \texttt{"KPM"}.
\item
  \texttt{mode="ED"}: exact diagonalization, for small chains and for checking.
  It accepts the submodes \texttt{"KPM"}, \texttt{"ED"}, \texttt{"INV"}, \texttt{"EX"}, \texttt{"CVM"},
  \texttt{"ROOTN"} and \texttt{"TD"}.
\end{itemize}

The default \texttt{es} and \texttt{delta} change from one method to another, so it is
best to always give them. A KPM line has the width \(2\delta\) at the
center of the many-body spectrum, and down to about 0.7 of it for low-energy
excitations of a long chain. It is not a Lorentzian: its peak is about 1.5
times higher than a Lorentzian of the same width and weight. So compare
peak heights only between calculations with the same method.

\subsection{Dynamical spin structure factor}

The dynamical spin structure factor is

\[S^{zz}_{ij}(\omega)=\sum_n\langle\mathrm{GS}|S^z_i|n\rangle\langle n|S^z_j|\mathrm{GS}\rangle\,\delta(\omega-\Delta_n).\]

The local one, \(i=j\), is what inelastic spin-flip spectroscopy with an STM
measures on a single magnetic atom. Its Fourier transform

\[S(q,\omega)=\frac1n\sum_{i,j}e^{iq(i-j)}S^{zz}_{ij}(\omega)\]

is what inelastic neutron scattering measures. We compute it from all the
site pairs:

\begin{lstlisting}
es = np.linspace(0, 4, 100)
qs = np.linspace(0, 2*np.pi, 41)
sqw = np.zeros((len(qs), len(es)))
for i in range(n):
    for j in range(n):
        (x, y) = sc.get_dynamical_correlator(name=(sc.Sz[i], sc.Sz[j]),
                                             es=es, delta=0.1)
        sqw += np.real(np.exp(1j*qs*(i-j))[:, None]*y[None, :])/n
\end{lstlisting}

For a Heisenberg chain the weight is largest at \(q=\pi\), the
antiferromagnetic wave vector, and its lower edge follows the two-spinon
dispersion \(\frac{\pi}{2}|\sin q|\) for long chains.

Two methods give the spin structure factor directly:

\begin{itemize}
\tightlist
\item
  \texttt{sc.\allowbreak{}get\_\allowbreak{}spin\_\allowbreak{}spectral\_\allowbreak{}function(i,\ j=None,\ es=.\allowbreak{}.\allowbreak{}.\allowbreak{},\ delta=.\allowbreak{}.\allowbreak{}.\allowbreak{},\ nex=20)}:
  returns \(S^{zz}_{ij}+(S^{+-}_{ij}+S^{-+}_{ij})/2\), which equals
  \(S^{xx}+S^{yy}+S^{zz}\). With \texttt{return\_\allowbreak{}poles=True} it also returns the
  three channels separately, so we can see which spin channel each
  excitation belongs to. \texttt{connected=True} removes the elastic peak
  \(\langle S^z_i\rangle\langle S^z_j\rangle\) at \(\omega=0\). It uses the
  SECTOR method below, so it needs \texttt{itensor\_\allowbreak{}version=3} or \texttt{"python"}.
  The sector states are shared by all the pairs \((i,j)\), so a full
  \(S(q,\omega)\) map costs about as much as one site. This is the better
  choice on a long chain. See \texttt{examples/dynamical\_\allowbreak{}correlator/sector\_\allowbreak{}spin\_\allowbreak{}structure\_\allowbreak{}factor}.
\item
  \texttt{sc.\allowbreak{}get\_\allowbreak{}full\_\allowbreak{}SS\_\allowbreak{}correlator(mode="ED",\ i=0,\ j=None,\ es=.\allowbreak{}.\allowbreak{}.\allowbreak{},\ delta=.\allowbreak{}.\allowbreak{}.\allowbreak{})}:
  returns \(\frac13\sum_\alpha S^{\alpha\alpha}_{ij}(\omega)\), averaged over a
  degenerate ground-state manifold. This is what an unpolarized measurement
  on an isotropic magnet sees. ED only.
\end{itemize}

\subsection{Single-particle spectral function}

For a fermionic chain the single-particle spectral function is

\[A_{ij}(\omega)=\sum_n\langle\mathrm{GS}|c_i|n^{N+1}\rangle\langle n^{N+1}|c_j^\dagger|\mathrm{GS}\rangle\,\delta(\omega-\omega_n^+)
+\sum_m\langle\mathrm{GS}|c_j^\dagger|m^{N-1}\rangle\langle m^{N-1}|c_i|\mathrm{GS}\rangle\,\delta(\omega-\omega_m^-),\]

with \(\omega_n^+=E_n^{N+1}-E_0^N-\mu\) and
\(\omega_m^-=E_0^N-E_m^{N-1}-\mu\). The first term is electron addition, at
\(\omega>0\), and the second is electron removal, at \(\omega<0\). The local
one, \(A_{ii}(\omega)\), is the local density of states measured by STM
(\(dI/dV\)); its Fourier transform \(A(k,\omega)\) is measured by ARPES
(removal part) and inverse photoemission (addition part).

Here \texttt{fc} is a \texttt{Fermionic\_\allowbreak{}Chain} and \texttt{hc} a
\texttt{Spinful\_\allowbreak{}Fermionic\_\allowbreak{}Chain\_\allowbreak{}Native}:

\begin{lstlisting}
fc.set_conserved_sector(Nf=n//2)                  # the N-particle ground state
(x, A, info) = fc.get_spectral_function(i=0, es=np.linspace(-4, 4, 400),
                                        delta=0.1, nex=20, return_poles=True)
print(info["mu"], info["gap"])                    # mu and the charge gap

hc.set_conserved_sector(Nf=n, Sz=0)               # half-filled Hubbard chain
(x, A) = hc.get_spectral_function(i=0, spin="up", es=np.linspace(-6, 6, 400),
                                  delta=0.2, nex=20)
\end{lstlisting}

The chemical potential \(\mu=(E_0^{N+1}-E_0^{N-1})/2\) is subtracted by
default, so the gap is centered at \(\omega=0\). Pass \texttt{shift=None} to keep
the raw frequencies. \texttt{info} also gives the charge gap
\(E_0^{N+1}+E_0^{N-1}-2E_0^N\) and the two halves separately. This method
needs \texttt{itensor\_\allowbreak{}version=3} or \texttt{"python"}. See
\texttt{examples/dynamical\_\allowbreak{}correlator/sector\_\allowbreak{}spectral\_\allowbreak{}function\_\allowbreak{}hubbard}, where the
Mott gap opens with \(U\).

On other backends, or for a broad continuum, we build the two halves with
\texttt{get\_\allowbreak{}dynamical\_\allowbreak{}correlator}. The second operator acts first on the ground
state, so \((c_i,c_i^\dagger)\) is the addition part and
\((c_i^\dagger,c_i)\) the removal part:

\begin{lstlisting}
es = np.linspace(0, 4, 200)
(x, yp) = fc.get_dynamical_correlator(name=(fc.C[0], fc.Cdag[0]), es=es, delta=0.1)
(x, yh) = fc.get_dynamical_correlator(name=(fc.Cdag[0], fc.C[0]), es=es, delta=0.1)
w = np.concatenate([-es[::-1], es])               # removal at w<0, addition at w>0
A00 = np.concatenate([yh.real[::-1], yp.real])
\end{lstlisting}

Here the frequency is measured from \(E_0^N\) in both halves, without the
\(\mu\) shift. If the chain is not in a sector, \(|\mathrm{GS}\rangle\) is the
global ground state, at whatever particle number it has.

\subsection{Any pair of operators}

\texttt{name=(A,\ B)} accepts any operators built from the chain operators, for
example a bond operator:

\begin{lstlisting}
A = hc.Cdagup[0]*hc.Cup[1]
(x, y) = hc.get_dynamical_correlator(name=(A, A.get_dagger()), es=es, delta=0.1)
\end{lstlisting}

The pair may also be operators already converted with \texttt{toMPO()} (section
2). This avoids building them again in a scan over parameters. It works
with \texttt{mode="ED"} and with the DMRG submodes \texttt{"EX"}, \texttt{"CVM"} and \texttt{"ROOTN"};
the other submodes raise an error and need the operator itself.

\subsection{Choosing a method}

The \texttt{submode} keyword selects how \(S_{AB}(\omega)\) is computed. All the
methods return the same quantity, defined above.

\begin{itemize}
\tightlist
\item
  \texttt{"KPM"} (default): the Kernel Polynomial Method. It expands the spectrum
  in Chebyshev polynomials of \(H\) and gives the whole frequency range at
  once. The cost grows as \(1/\delta\). Use it for a first look and for broad
  spectra.
\item
  \texttt{"CVM"}: the correction-vector method. It solves one linear system per
  frequency, so it is accurate at each \(\omega\) but the cost grows with
  the number of points in \texttt{es}. Use it to resolve a narrow window or a
  sharp peak. \texttt{"CVM\_\allowbreak{}explicit"} computes the same resolvent in a different
  way, and is useful as a cross-check.
\item
  \texttt{"ROOTN"}: the root-\(N\) Krylov correction vector of Nocera and Alvarez
  (\href{https://arxiv.org/abs/2204.03165}{arXiv:2204.03165}). It applies the
  resolvent in \texttt{N} smaller steps, each in a Krylov space of size \texttt{nkry}.
  Use it for high frequencies, near the top of the spectrum, where a
  single correction vector needs a large bond dimension. It is the most
  expensive method.
\item
  \texttt{"TD"}: real-time evolution of \(C(t)=\langle\mathrm{GS}|A(t)B(0)|\mathrm{GS}\rangle\)
  followed by a Fourier transform with the damping \(e^{-\delta t}\). Use it
  for fine resolution and when time evolution is cheap (short-range
  Hamiltonians, small entanglement growth). The time propagator is the one
  of section 7.
\item
  \texttt{"TDZ"}: the same, but the evolution follows a complex-time contour (Cao,
  Lu, Stoudenmire and Parcollet,
  \href{https://arxiv.org/abs/2311.10909}{arXiv:2311.10909}). The bond dimension
  grows much more slowly than in \texttt{"TD"}, so it reaches longer times.
\item
  \texttt{"EX"}: an explicit sum over the lowest \texttt{nex} excited states found by
  DMRG. Use it when a few low-energy states carry the physics, for example
  in a small gapped system.
\item
  \texttt{"SECTOR"}: an explicit sum over the lowest \texttt{nex} eigenstates of the
  quantum-number sector that \(B|\mathrm{GS}\rangle\) belongs to (\(N+1\) for
  \(c^\dagger\), \(S^z+1\) for \(S^+\)). Use it for sharp low-energy
  excitations: the poles come out at converged energies with exact weights.
  It needs \texttt{itensor\_\allowbreak{}version=3} or \texttt{"python"}. \texttt{get\_\allowbreak{}spectral\_\allowbreak{}function} and
  \texttt{get\_\allowbreak{}spin\_\allowbreak{}spectral\_\allowbreak{}function} are built on it.
\item
  \texttt{"ED"} and \texttt{"INV"} (\texttt{mode="ED"} only): the exact Lehmann sum and the
  exact resolvent. These are the references to check the other methods.
\item
  \texttt{"maxent"} and \texttt{"CVMimag"}: need the separate modules \texttt{dmrgpy.\allowbreak{}maxenttk}
  and \texttt{dmrgpy.\allowbreak{}padetk}, which are not distributed with dmrgpy. Without them
  they raise an error.
\end{itemize}

As a rule: KPM for the full spectrum, CVM or TD for a narrow window at
high resolution, TDZ when TD needs too large a bond dimension, EX or
SECTOR when a few states are enough.

\begin{lstlisting}
pair = (sc.Sz[0], sc.Sz[0])
(x, y) = sc.get_dynamical_correlator(submode="CVM", name=pair, es=es, delta=0.1)
(x, y) = sc.get_dynamical_correlator(submode="TD", name=pair, es=es, delta=0.1, dt=0.05)
(x, y) = sc.get_dynamical_correlator(submode="EX", name=pair, es=es, delta=0.1, nex=20)
(x, y) = sc.get_dynamical_correlator(mode="ED", submode="ED", name=pair, es=es, delta=0.1)
\end{lstlisting}

\textbf{Keywords of each method.} The accuracy of every method also depends on
the ground state itself, so \texttt{maxm} and \texttt{nsweeps} (section 3) come first.

\begin{itemize}
\tightlist
\item
  \texttt{sc.\allowbreak{}kpmmaxm} (KPM): the bond dimension of the Chebyshev vectors. Increase
  it until the spectrum stops changing.
\item
  \texttt{sc.\allowbreak{}kpm\_\allowbreak{}scale} (KPM, default 0.7): how much of \([-1,1]\) the spectrum of
  \(H\) fills after rescaling. Do not go below 0.5; the calculation raises an
  error when the expansion becomes unstable.
\item
  \texttt{sc.\allowbreak{}kpm\_\allowbreak{}n\_\allowbreak{}scale} (KPM, default 1): a positive integer that multiplies the
  number of Chebyshev moments, for a line sharper than \(2\delta\).
\item
  \texttt{kernel=} (KPM): how the moments become a spectrum, \texttt{"jackson"}
  (default), \texttt{"lorentz"}, \texttt{"plain"} or \texttt{"hodc"}. The last is the high-order
  kernel of \href{https://arxiv.org/abs/2512.03149}{arXiv:2512.03149}, with
  \texttt{hodc\_\allowbreak{}order} (default 6) and \texttt{hodc\_\allowbreak{}eta} (default \texttt{delta}). It is more
  accurate where the spectrum is a smooth continuum, but it can be slightly
  negative and is more sensitive to a small \texttt{kpmmaxm}. See
  \texttt{examples/dynamical\_\allowbreak{}correlator/hodc\_\allowbreak{}VS\_\allowbreak{}jackson\_\allowbreak{}kernel}.
\item
  \texttt{sc.\allowbreak{}kpm\_\allowbreak{}energy\_\allowbreak{}truncate=True} (KPM, \texttt{itensor\_\allowbreak{}version=3} and \texttt{"python"}):
  energy truncation of Holzner et al.,
  \href{https://doi.org/10.1103/PhysRevB.83.195115}{PRB 83, 195115 (2011)}. It
  allows \texttt{kpm\_\allowbreak{}scale} well below 0.5, so that more moments are spent on the
  low-energy window. It is slower per moment. The settings are
  \texttt{kpm\_\allowbreak{}truncate\_\allowbreak{}dK} (increase until converged, 30 is a good value),
  \texttt{kpm\_\allowbreak{}truncate\_\allowbreak{}nsweeps} and \texttt{kpm\_\allowbreak{}truncate\_\allowbreak{}threshold}. See
  \texttt{examples/dynamical\_\allowbreak{}correlator/dynamical\_\allowbreak{}correlator\_\allowbreak{}kpm\_\allowbreak{}energy\_\allowbreak{}truncation}.
\item
  \texttt{sc.\allowbreak{}cvm\_\allowbreak{}maxm} and \texttt{sc.\allowbreak{}cvm\_\allowbreak{}tol} (CVM): the bond dimension of the
  correction vector and the relative tolerance of its solver (default
  \(10^{-5}\)). If a frequency point warns that it did not converge,
  increase \texttt{cvm\_\allowbreak{}maxm}.
\item
  \texttt{N} and \texttt{nkry} (ROOTN, defaults 8 and 20): the number of steps and the
  Krylov dimension. Larger \texttt{N} helps at high frequency when \texttt{nkry} is
  small.
\item
  \texttt{dt} and \texttt{damping\_\allowbreak{}periods} (TD and TDZ): the time step, and the total
  time \(T\) in units of \(1/\delta\) (default 6). The resolution is set by
  \(T\).
\item
  \texttt{damping} and \texttt{predict} (TD): the time window, \texttt{"exp"} (default, a
  Lorentzian line), \texttt{"gaussian"} (faster decaying tails, line 1.2 times
  wider) or \texttt{"parzen"}, and linear prediction of \(C(t)\) to longer times
  (default \texttt{True}), which makes the line sharper and more accurate when
  the simulated time is short.
\item
  \texttt{alpha0} and \texttt{n\_\allowbreak{}max} (TDZ, defaults 0.1 and 4): the angle of the time
  contour and the order of the expansion back to real time. A larger
  \texttt{alpha0} needs a smaller bond dimension but a larger \texttt{n\_\allowbreak{}max}, at most 4.
\item
  \texttt{nex} (EX and SECTOR): the number of states in the sum. With
  \texttt{return\_\allowbreak{}poles=True}, SECTOR also returns the poles and their weights,
  and \texttt{info{[}"captured"{]}} is the fraction of the weight
  \(\langle\mathrm{GS}|B^\dagger B|\mathrm{GS}\rangle\) they account for. A
  warning appears below 0.9; increase \texttt{nex} then.
\end{itemize}

\textbf{Reusing the KPM moments.} The Chebyshev moments are the expensive part
of KPM. We can compute them once and build the spectrum with several
kernels:

\begin{lstlisting}
from dmrgpy import kpmdmrg
mus, emin, emax, scale, npol, delta = sc.get_dynamical_correlator_moments(
        name=(sc.Sz[0], sc.Sz[0]), delta=0.1)
(x, y) = kpmdmrg.dynamical_correlator_from_moments(mus, emin, emax, scale,
        npol, es, kernel="hodc", delta=delta)
\end{lstlisting}

\subsection{Degenerate ground states}

With \texttt{mode="ED",\ submode="ED"}, a degenerate ground state is handled by
averaging the correlator over all the states with excitation energy below
\texttt{dex} (default \(10^{-5}\)), with equal weights. This is a hard cutoff, so in
a scan where a level splitting crosses \texttt{dex} (a Zeeman field, for example)
the result jumps. A warning appears when a level is close to \texttt{dex}. For a
scan, use a small temperature instead, \texttt{T=0.\allowbreak{}01}, which weights the states
with Boltzmann factors and changes smoothly (section 9). See
\texttt{examples/kondo/atom\_\allowbreak{}iets\_\allowbreak{}orbital\_\allowbreak{}resolved}.

\subsection{Non-Hermitian Hamiltonians}

For a non-Hermitian \(H\) (section 4) the ground state is a pair of left and
right eigenstates, and the correlator is
\(\langle\psi_L|A(z)B|\psi_R\rangle\). \texttt{submode="KPM"} then uses the
non-Hermitian KPM of \href{https://doi.org/10.1103/PhysRevLett.130.100401}{PRL 130, 100401},
and needs \texttt{E\_\allowbreak{}max}, an upper bound on the spectral radius of \(H\). It
recomputes the moments at every frequency, so it is much slower. \texttt{"CVM"},
\texttt{"CVM\_\allowbreak{}explicit"} and \texttt{"EX"} also work; the other submodes raise an error.
Non-Hermitian KPM works with \texttt{mode="ED"}, \texttt{itensor\_\allowbreak{}version=3} and
\texttt{"python"}. See \texttt{examples/non\_\allowbreak{}hermitian/nhkpm\_\allowbreak{}v3\_\allowbreak{}VS\_\allowbreak{}ED}.

\section{Real-time dynamics: quenches}

In this section we evolve a state in real time,
\(|\psi(t)\rangle=e^{-iHt}|\psi(0)\rangle\), and measure an observable along
the way. The typical case is a quantum quench: we prepare the ground state
of a Hamiltonian \(H_0\), change the Hamiltonian to \(H_1\) at \(t=0\), and follow
how observables oscillate, relax or thermalize. Here \texttt{h0} and \texttt{h1} are two
Hamiltonians of the chain \texttt{sc}, for example a staggered field and the
Heisenberg chain of section 3.

\begin{lstlisting}
from dmrgpy import timedependent
sc.set_hamiltonian(h0)
wf0 = sc.get_gs()                          # ground state of H0
sc.set_hamiltonian(h1)                     # quench to H1
(ts, sz) = timedependent.evolve_and_measure(sc, operator=sc.Sz[0],
                                            nt=200, dt=0.02, wf=wf0)
\end{lstlisting}

This gives \(\langle\psi(t)|S^z_0|\psi(t)\rangle\) at the times
\(t=0,\,dt,\,2dt,\dots\). The keywords are:

\begin{itemize}
\tightlist
\item
  \texttt{nt}, \texttt{dt}: the number of time steps (default 1000) and the time step
  (default 0.01). A smaller \texttt{dt} is more accurate.
\item
  \texttt{wf}: the initial state. Without it, the ground state of the chain is
  used.
\item
  \texttt{h}: the Hamiltonian of the evolution, if not the one of the chain.
\item
  \texttt{mode="ED"}: exact evolution, the reference for small chains.
\item
  \texttt{return\_\allowbreak{}wf=True} (DMRG): also return the final state.
\end{itemize}

The accuracy of the DMRG evolution is set by \texttt{sc.\allowbreak{}maxm} and \texttt{dt}. The
entanglement grows with time after a quench, so the bond dimension needed
grows too. When the result stops agreeing with a larger \texttt{maxm}, the
simulation has reached its maximum time.

\textbf{Local quench.} \texttt{evolution\_\allowbreak{}ABA} first applies an operator \(A\) to the
state, for example a spin flip or an added electron, and then measures \(B\):

\[\langle\psi|A^\dagger e^{iHt}Be^{-iHt}A|\psi\rangle.\]

Here we flip up the spin at the edge of the Heisenberg chain and follow
how the magnetization arrives at site 3:

\begin{lstlisting}
Sp0 = sc.Sx[0] + 1j*sc.Sy[0]               # S^+ on site 0
(ts, sz3) = timedependent.evolution_ABA(sc, A=Sp0, B=sc.Sz[3], nt=200, dt=0.02)
\end{lstlisting}

It takes the same keywords as \texttt{evolve\_\allowbreak{}and\_\allowbreak{}measure}, and starts from the
ground state of the chain unless \texttt{wf} is given. Note that \(A\) is applied as
it is, so the state \(A|\psi\rangle\) is not normalized.

\textbf{Evolved states.} To get the states themselves, \texttt{sc.\allowbreak{}exponential(-1j*t*h,\ wf)} returns \(e^{-iHt}|\psi\rangle\) for one time (section 2), and
\texttt{timeevolution.\allowbreak{}evolve\_\allowbreak{}WF(h,\ wf,\ ts=ts)} returns a list of states, one for
each time in \texttt{ts}. Note that \texttt{evolve\_\allowbreak{}WF} applies \(e^{+iht}\), so pass \texttt{-h}
for the physical evolution. With the states, we compute any overlap, for
example the return amplitude \(\langle\psi(0)|\psi(t)\rangle\).

\textbf{Choosing the propagator.} \texttt{sc.\allowbreak{}tevol\_\allowbreak{}method} selects the algorithm:

\begin{itemize}
\tightlist
\item
  \texttt{"TDVP"} (default): two-site TDVP. It works for any Hamiltonian and
  grows the bond dimension as needed. On \texttt{itensor\_\allowbreak{}version=2} it is
  replaced by \texttt{"MPO"}.
\item
  \texttt{"TDVP\_\allowbreak{}GSE"}: one-site TDVP with global subspace expansion (Yang and
  White, \href{https://arxiv.org/abs/2005.06104}{PRB 102, 094315 (2020)}). Use
  it when the initial state has a small bond dimension, for example a
  product state. The bond dimension grows only during the first
  \texttt{sc.\allowbreak{}tdvp\_\allowbreak{}gse\_\allowbreak{}sweeps} steps (default 3); the other settings are
  \texttt{sc.\allowbreak{}tdvp\_\allowbreak{}gse\_\allowbreak{}krylov\_\allowbreak{}order} (default 3) and \texttt{sc.\allowbreak{}tdvp\_\allowbreak{}gse\_\allowbreak{}cutoff}
  (default \(10^{-8}\)).
\item
  \texttt{"TEBD"}: second-order Trotter evolution with two-site gates. Faster
  than TDVP, but only for nearest-neighbor Hamiltonians; otherwise it
  raises an error. A \texttt{Spinful\_\allowbreak{}Fermionic\_\allowbreak{}Chain\_\allowbreak{}Native} Hubbard chain is
  nearest-neighbor, the interleaved \texttt{Spinful\_\allowbreak{}Fermionic\_\allowbreak{}Chain} is not.
\item
  \texttt{"AUTO"}: \texttt{"TEBD"} when the Hamiltonian is nearest-neighbor, \texttt{"TDVP"}
  otherwise.
\item
  \texttt{"MPO"}: a second-order Taylor expansion of \(e^{-iH\,dt}\) applied as an
  MPO. The only option on \texttt{itensor\_\allowbreak{}version=2}, and less accurate than TDVP
  at the same bond dimension.
\end{itemize}

\begin{lstlisting}
sc.tevol_method = "TEBD"
\end{lstlisting}

The same propagator is used by the \texttt{"TD"} and \texttt{"TDZ"} dynamical
correlators of section 6. See \texttt{examples/time\_\allowbreak{}evolution/time\_\allowbreak{}evolution\_\allowbreak{}quench}.

\section{Density of states}

``Density of states'' can mean two different quantities, and only the second
one has a method.

\textbf{Many-body density of states.} This is the density of all the
eigenstates of \(H\),

\[\rho(E)=\sum_n\delta(E-E_n).\]

There is no method for it. \texttt{get\_\allowbreak{}distribution} (section 14) is not a
replacement: it computes a ground-state expectation value
\(\langle\mathrm{GS}|B\,\delta(X)\,A|\mathrm{GS}\rangle\), not a trace over
all the states. For a small chain, the full ED spectrum from
\texttt{get\_\allowbreak{}excited(mode="ED",\ n=.\allowbreak{}.\allowbreak{}.\allowbreak{})} (section 4) gives \(\rho(E)\) directly.

\textbf{Local density of states.} For fermions, the density of states measured
by STM (\(dI/dV\)) is the local single-particle spectral function

\[A_i(\omega)=\sum_n|\langle n^{N+1}|c_i^\dagger|\mathrm{GS}\rangle|^2\delta(\omega-\omega_n^+)
+\sum_m|\langle m^{N-1}|c_i|\mathrm{GS}\rangle|^2\delta(\omega-\omega_m^-),\]

with electron addition at \(\omega>0\) and electron removal at \(\omega<0\).
This is \(A_{ii}(\omega)\) of section 6, and we compute it with
\texttt{get\_\allowbreak{}spectral\_\allowbreak{}function(i=i)}, or from the two correlators
\((c_i,c_i^\dagger)\) and \((c_i^\dagger,c_i)\) as shown there. On a spinful
chain, pass \texttt{spin="up"} or \texttt{spin="dn"} and add the two.

\section{Finite temperature}

In this section we compute thermal averages,

\[\langle O\rangle_T=\frac{\mathrm{Tr}\,[e^{-\beta H}O]}{\mathrm{Tr}\,e^{-\beta H}},
\qquad\beta=1/T.\]

There are three methods: purification, METTS and exact diagonalization.

\textbf{Purification.} Each physical site gets an ancilla site. The product of
singlets between each site and its ancilla is a pure state whose reduced
density matrix on the physical chain is \(\rho\propto\mathbb 1\), the
\(T=\infty\) state. Evolving it in imaginary time with the physical \(H\),

\[|\Psi(\beta)\rangle=e^{-\beta H/2}|\Psi(0)\rangle,\]

and tracing out the ancillas gives \(\rho(T)\propto e^{-\beta H}\).

\begin{lstlisting}
from dmrgpy import thermal
n = 6
tc = thermal.Thermal_Spin_Chain(["S=1/2"]*n, T=0.5)
h = sum(tc.Sx[i]*tc.Sx[i+1] + tc.Sy[i]*tc.Sy[i+1] + tc.Sz[i]*tc.Sz[i+1]
        for i in range(n-1))
tc.set_hamiltonian(h)
tc.get_gs()                                   # builds |Psi(beta)>
E = tc.MBChain.vev(h).real                    # thermal energy
czz = tc.MBChain.vev(tc.Sz[0]*tc.Sz[1]).real  # thermal <Sz_0 Sz_1>
\end{lstlisting}

\texttt{tc.\allowbreak{}Sx}, \texttt{tc.\allowbreak{}Sy}, \texttt{tc.\allowbreak{}Sz} are the operators of the physical sites, and
\texttt{tc.\allowbreak{}MBChain} is the doubled chain that holds the purified state. Static
expectation values on \texttt{tc.\allowbreak{}MBChain} are thermal averages. A dynamical
correlator on \texttt{tc.\allowbreak{}MBChain} is not the thermal one, so use METTS or ED for
those. \texttt{T=0} gives the ordinary ground state. The imaginary-time evolution
is accurate to about \(10^{-6}\) relative at the defaults. The keywords are:

\begin{itemize}
\tightlist
\item
  \texttt{tc.\allowbreak{}anneal\_\allowbreak{}step}: the size of each imaginary-time step, in units of the
  spectral width (default 2). Smaller is more accurate and slower.
\item
  \texttt{tc.\allowbreak{}anneal\_\allowbreak{}order}: the order of the expansion of each step (default 8).
\item
  \texttt{tc.\allowbreak{}MBChain.\allowbreak{}maxm}: the bond dimension of the purified state. It needs
  to be larger at intermediate temperatures.
\end{itemize}

See \texttt{examples/finite\_\allowbreak{}temperature/thermal\_\allowbreak{}purification\_\allowbreak{}VS\_\allowbreak{}exact}.

\textbf{METTS.} Minimally entangled typical thermal states (Stoudenmire and
White, arXiv:1002.1305) sample product states \(|i\rangle\) with a Markov
chain. Each one is evolved to
\(|\phi_i\rangle\propto e^{-\beta H/2}|i\rangle\) and then collapsed to a new
product state. The plain average of \(\langle\phi_i|O|\phi_i\rangle\) over
the chain is the thermal average. The states stay weakly entangled, so
no ancillas are needed. Here \texttt{sc} is the Heisenberg chain of section 3:

\begin{lstlisting}
T = 0.5
mean, err = sc.metts_vev(sc.Sz[0]*sc.Sz[1], T, nsamples=300, nwarmup=30)
res = sc.metts_vev([sc.Sz[0], sc.Sz[1], h], T)   # list of (mean, err)
\end{lstlisting}

Being a Monte Carlo method, it returns a mean and a statistical error.
The error assumes independent samples, so it is too small when samples
are correlated. Measuring several operators in one call is much cheaper
than one call per operator, since they share the samples. The keywords
are:

\begin{itemize}
\tightlist
\item
  \texttt{nsamples}, \texttt{nwarmup}: the number of samples, and the number of first
  steps discarded for equilibration.
\item
  \texttt{dbeta\_\allowbreak{}half\_\allowbreak{}step}: the imaginary-time step (default 0.05).
\item
  \texttt{basis\_\allowbreak{}ops}: the two bases used in turn for the collapse (default
  \texttt{("Sz","Sx")}). Alternating them reduces autocorrelation.
\item
  \texttt{njobs}: runs independent Markov chains in parallel processes. Only
  for \texttt{itensor\_\allowbreak{}version="python"}.
\end{itemize}

METTS works with \texttt{itensor\_\allowbreak{}version=3} and \texttt{"python"}. It is not available
on \texttt{itensor\_\allowbreak{}version=2}, where it raises an error.

The same sampling gives real-time thermal correlators
\(C_{AB}(t)=\langle A(t)B\rangle_T\) (arXiv:2405.18484). Each sample
\(|\psi_i\rangle\) gives \(\langle\psi_i|e^{iHt}Ae^{-iHt}B|\psi_i\rangle\) by
real-time evolution, and the average is \(C_{AB}(t)\):

\begin{lstlisting}
ts, c, err = sc.metts_dynamical_correlator((sc.Sz[0], sc.Sz[0]), T,
                 nt=100, dt=0.1, nsamples=200, nwarmup=30)
\end{lstlisting}

The result is in the time domain, on \(t=0,\Delta t,\dots,(n_t-1)\Delta t\).
For a spectrum, apply a window and a Fourier transform yourself.

\textbf{Exact diagonalization.} For small chains we sum over the eigenstates,
\(\langle O\rangle_T=\sum_n p_n\langle n|O|n\rangle\) with
\(p_n=e^{-E_n/T}/Z\). Here \texttt{sc} is a short chain, \texttt{n} of about 10 sites:

\begin{lstlisting}
sc.vev(sc.Sz[0]*sc.Sz[1], mode="ED", T=0.5)
sc.get_correlation_matrix(T=0.5, operators=[sc.Sz[i] for i in range(n)])
sc.get_dynamical_correlator(mode="ED", submode="ED", T=0.5,
                            name=(sc.Sz[0], sc.Sz[0]))
\end{lstlisting}

The sum uses the full spectrum when the Hilbert space has at most about
2000 states. Above that, only the \texttt{n=} lowest states are used, and an
error is raised if the last one still has a large Boltzmann weight. The
ED dynamical correlator is the exact reference for
\texttt{metts\_\allowbreak{}dynamical\_\allowbreak{}correlator} (see
\texttt{examples/finite\_\allowbreak{}temperature/dynamical\_\allowbreak{}metts\_\allowbreak{}VS\_\allowbreak{}ED}).

\section{Topological invariants}

\textbf{Many-body Berry phase.} Let the Hamiltonian depend on a parameter
\(\phi\) that goes around a closed loop, for example a flux \(\phi\) through a
ring, entering as a twist \(e^{i\phi}\) on one bond. The discrete Berry
phase of the ground state is

\[\gamma=\arg\prod_{k}\langle\psi(\phi_k)|\psi(\phi_{k+1})\rangle,\]

with the last state connected to the first one. With inversion symmetry
\(\gamma\) is quantized to \(0\) or \(\pi\), and the two values are two
different phases, for example the two dimerizations of a spin chain. We
compute it by solving the ground state at each \(\phi_k\) and multiplying
the overlaps. Here \texttt{h\_\allowbreak{}of(phi)} returns the twisted Hamiltonian of \texttt{sc}:

\begin{lstlisting}
import numpy as np
phis = np.linspace(0, 2*np.pi, 20, endpoint=False)
wfs = []
for phi in phis:
    sc.set_hamiltonian(h_of(phi))
    wfs.append(sc.get_gs())
prod = np.prod([wfs[i].dot(wfs[(i+1) % len(wfs)]) for i in range(len(wfs))])
gamma = np.angle(prod)        # 0 or pi
\end{lstlisting}

See \texttt{examples/topological/zak\_\allowbreak{}phase} for the dimerized Heisenberg chain.

\textbf{Single-particle Berry phase.} For a Bloch Hamiltonian \(H(k)\), the Zak
phase of the occupied bands is the phase of the Wilson loop,

\[\gamma=\arg\det\prod_k U(k,k+\delta k),\qquad
U_{mn}(k,k+\delta k)=\langle u_m(k)|u_n(k+\delta k)\rangle,\]

with \(m,n\) running over the occupied bands. It gives the polarization of
the band. Here \texttt{hk(k)} returns the Bloch matrix, with \(k\) from 0 to 1:

\begin{lstlisting}
from dmrgpy import topology
gamma = topology.berry_phase_matrix(hk, nk=40)   # the lower half of the bands is occupied
\end{lstlisting}

\textbf{Fermion parity.} For a fermionic chain the total parity is

\[P=\Big\langle\prod_i(1-2n_i)\Big\rangle.\]

It is \(+1\) or \(-1\) for a state with an even or odd number of fermions. In
a chain with superconducting pairing the particle number is not
conserved, but the parity is. A change of the ground-state parity as a
function of a parameter is a level crossing between the two sectors, as
in a Kitaev chain or a magnetic impurity in a superconductor. Here \texttt{fc} is
a \texttt{Fermionic\_\allowbreak{}Chain}:

\begin{lstlisting}
wf = fc.get_gs()
p = wf.get_fermionic_parity()                     # +1 or -1
p = wf.get_fermionic_parity(fpmode="iterative")   # same number, other route
\end{lstlisting}

See \texttt{examples/topological/parity} for \(P\) as a function of the chemical
potential.

\section{Mean-field decoupling}

For a spin Hamiltonian with exchange couplings \(J_{ij}\), the
self-consistent mean-field (Weiss-field) decoupling replaces the exchange
by a field on each site,

\[H_{\rm MF}=p\,H_{\rm exch}+H_{\rm onsite}+\sum_i\mathbf h_i\cdot\mathbf S_i,
\qquad\mathbf h_i=(1-p)\sum_jJ_{ij}\langle\mathbf S_j\rangle.\]

We solve \(H_{\rm MF}\), compute the new \(\langle\mathbf S_i\rangle\), rebuild
\(\mathbf h_i\), mix the old and new values, and repeat until the
magnetization stops changing. With \(p=0\) this is pure mean-field theory.
With \(0<p<1\) a fraction \(p\) of the exchange is kept and treated exactly,
together with the field. With \(p=1\) it is the original model. The
couplings are read from the Hamiltonian of the chain, so any one- and
two-site spin Hamiltonian works, including anisotropic and long-range
exchange. Here \texttt{sc} is the Heisenberg chain of section 3:

\begin{lstlisting}
from dmrgpy import meanfield
n = sc.ns
m0 = [[0, 0, 0.5*(-1)**i] for i in range(n)]       # staggered start
mf = meanfield.spinchain_meanfield(sc, p=0.0, m0=m0, mix=0.5)
m = mf.get_magnetization()       # self-consistent <S_i>, a 3 x n array
e = mf.gs_energy()               # mean-field energy
\end{lstlisting}

The function returns a new chain whose Hamiltonian is the converged
\(H_{\rm MF}\). This Hamiltonian includes the constant
\(-(1-p)\sum_{ij}J_{ij}\langle\mathbf S_i\rangle\cdot\langle\mathbf S_j\rangle\),
so the exchange is not counted twice. At \(p=0\) its \texttt{gs\_\allowbreak{}energy()} is the
expectation value of the original Hamiltonian in the mean-field state.
The keywords are:

\begin{itemize}
\tightlist
\item
  \texttt{p}: the fraction of the exchange kept exactly.
\item
  \texttt{m0}: the starting magnetization, one 3-vector per site. Random by
  default. For an antiferromagnet start from a staggered pattern, since
  simple mixing can oscillate otherwise.
\item
  \texttt{mix}: the weight of the new magnetization in each step (default 0.9).
  Lower it if the loop oscillates.
\item
  \texttt{maxerror}, \texttt{maxite}: the convergence tolerance and the maximal number
  of iterations. After \texttt{maxite} the loop stops with a warning.
\item
  \texttt{mixmode}: \texttt{"default"} (linear mixing) or \texttt{"broyden"}.
\item
  \texttt{mode="ED"}: solve each step with exact diagonalization.
\end{itemize}

\texttt{meanfield.\allowbreak{}decompose\_\allowbreak{}spin\_\allowbreak{}hamiltonian(sc)} returns the onsite fields
\texttt{b{[}i,a{]}}, the exchange \texttt{J{[}i,j,a,b{]}} and the constant read from the
Hamiltonian. A Hamiltonian that is not of this form, for example with a
three-site term, raises an error.

\section{Fidelity susceptibility and quantum phase transitions}

Let the Hamiltonian depend on a parameter, \(H(\lambda)=H_0+\lambda H_1\).
The fidelity susceptibility measures how fast the ground state changes
with \(\lambda\). In perturbation theory it is

\[\chi(\lambda)=\sum_{n\neq0}\frac{|\langle 0|H_1|n\rangle|^2}{(E_n-E_0)^2+\delta^2}.\]

At a quantum phase transition the gap closes and \(\chi\) has a peak that
grows with system size. So a scan of \(\chi(\lambda)\) locates a critical
point without knowing the order parameter. Here \texttt{sc} is a spin chain:

\begin{lstlisting}
from dmrgpy import fidelity
h0 = 4*sum(sc.Sz[i]*sc.Sz[i+1] for i in range(n-1))   # Ising coupling
h1 = 2*sum(sc.Sx[i] for i in range(n))                # transverse field
chi = fidelity.get_fidelity(sc, h0, h1, 1.0)               # default
chi_pt = fidelity.get_fidelity(sc, h0, h1, 1.0, fmode="PT")  # formula above
\end{lstlisting}

The default, \texttt{fmode="derivative"}, does not use the formula above. It
computes the second derivative of the ground-state overlap by finite
differences, so it needs only ground states. It also handles a degenerate
ground state. \texttt{fmode="PT"} sums over the \texttt{n} lowest states. Increase \texttt{n}
until \(\chi\) stops changing. The keywords are:

\begin{itemize}
\tightlist
\item
  \texttt{dl}: the finite-difference step in \(\lambda\) (default 0.1). Use a
  smaller value when \(\chi\) changes fast.
\item
  \texttt{n}, \texttt{delta}: for the default estimator, the number of low states
  searched for a degenerate ground state, and the energy tolerance for
  calling two states degenerate. For \texttt{fmode="PT"}, \texttt{n} is the number of
  states in the sum (default 2) and \texttt{delta} is the \(\delta\) of the
  formula above.
\item
  \texttt{mode="ED"}: exact diagonalization, for small chains.
\end{itemize}

\section{Ground-state degeneracy}

A degenerate ground state signals a broken symmetry or a topological
phase. Examples are the two ordered states of an Ising chain and the four
edge states of an open Haldane chain. We count the levels close to \(E_0\),

\[g\approx\sum_i\exp\!\left[-\left(\frac{(E_i-E_0)^2}{\delta}\right)^2\right],\]

adding excited states \(E_i\) until the count stops growing:

\begin{lstlisting}
g = sc.get_gs_degeneracy()             # close to an integer
g = sc.get_gs_degeneracy(delta=1e-4)   # a stricter window
\end{lstlisting}

A level counts when \(|E_i-E_0|\) is smaller than about \(\sqrt{\delta}\),
which is 0.1 at the default \texttt{delta=1e-2}. A result that is not close to
an integer means that a level sits at the edge of the window. On a finite
chain a degeneracy is often split by an amount that decays with the
length, so choose \texttt{delta} relative to that splitting. \texttt{mode="ED"} uses
exact diagonalization.

\section{Reduced density matrices and operator distributions}

\textbf{Reduced density matrix.} The reduced density matrix of one site,

\[\rho_i=\mathrm{Tr}_{j\neq i}|\mathrm{GS}\rangle\langle\mathrm{GS}|,\]

contains every local observable of that site, and its eigenvalues give the
site entanglement entropy (section 5).

\begin{lstlisting}
rho = sc.get_rdm(i=0)     # d x d matrix, d the local dimension
\end{lstlisting}

It is computed from the MPS, so it is not available with \texttt{mode="ED"},
where it raises an error.

\textbf{Operator distributions.} For a Hermitian operator \(X\), the expectation
value \(\langle X\rangle\) is only the mean. The full distribution of the
measured values of \(X\) in the ground state is

\[P(x)=\langle\mathrm{GS}|\,\delta(X-x)\,|\mathrm{GS}\rangle,\qquad
\int P(x)\,dx=1.\]

For a conserved charge this is the full counting statistics. A sharp
\(P(x)\) means that the ground state has a well-defined value of \(X\), and a
broad one means large fluctuations. It is computed with the kernel
polynomial method, as the dynamical correlators of section 6:

\begin{lstlisting}
X = sum(sc.Sz[i] for i in range(n))      # total magnetization
x, p = sc.get_distribution(X=X, delta=0.1)
mus, shift, scale = sc.get_distribution_moments(X=X, delta=0.1)
\end{lstlisting}

\texttt{delta} sets the resolution through the number of Chebyshev moments.
Unlike in section 6, it is not calibrated as a broadening, so compare
distributions computed with the same \texttt{delta}. \texttt{get\_\allowbreak{}distribution} also
works with \texttt{mode="ED"}. \texttt{get\_\allowbreak{}distribution\_\allowbreak{}moments} returns the raw
Chebyshev moments of the rescaled operator and has no ED version. A
maximum-entropy reconstruction from the moments \(\langle X^k\rangle\),
\texttt{distribution.\allowbreak{}get\_\allowbreak{}distribution\_\allowbreak{}maxent}, needs the module
\texttt{dmrgpy.\allowbreak{}maxenttk}, which is not shipped, and raises an error without it.

\section{Worked-example cookbook}

Each recipe starts from a chain \texttt{sc} of \texttt{n} sites, built as in section 3
with the Hamiltonian given.

\textbf{Central charge of the critical Ising chain.} For
\(H=\sum_iS_i^zS_{i+1}^z+\tfrac12\sum_iS_i^x\), at the critical field, the
entanglement entropy of the open chain follows the Calabrese-Cardy formula
with \(c=1/2\) (section 5):

\begin{lstlisting}
sc.maxm = 200          # critical chains need a large bond dimension
wf = sc.get_gs()
c = wf.get_CFT_central_charge()
\end{lstlisting}

\textbf{Haldane gap of the spin-1 chain.} The open chain has four low states
from the two spin-1/2 edge states. The bulk gap is the fifth state
(section 4):

\begin{lstlisting}
sc = spinchain.Spin_Chain(["S=1" for i in range(n)])
# ... Heisenberg h, set_hamiltonian(h) ...
es = sc.get_excited(n=6)
gap = es[4] - es[0]
\end{lstlisting}

\textbf{Gaps of a Hubbard chain.} Here \texttt{fc} is a \texttt{Spinful\_\allowbreak{}Fermionic\_\allowbreak{}Chain}
with a Hubbard Hamiltonian. \texttt{get\_\allowbreak{}gap()} is the gap to the first excited
state, and \texttt{get\_\allowbreak{}charge\_\allowbreak{}gap(d=.\allowbreak{}.\allowbreak{}.\allowbreak{})} is \(E_0(N+d)-E_0(N)\) (section 4):

\begin{lstlisting}
fc.get_gap()
fc.get_charge_gap(d=1)
fc.get_charge_gap(d=2)
\end{lstlisting}

\textbf{Fidelity susceptibility across the Ising transition} (section 12):

\begin{lstlisting}
import numpy as np
from dmrgpy import fidelity
h0 = 4*sum(sc.Sz[i]*sc.Sz[i+1] for i in range(n-1))   # Ising coupling
h1 = 2*sum(sc.Sx[i] for i in range(n))                # transverse field
lambdas = np.linspace(0.5, 1.5, 11)
chis = [fidelity.get_fidelity(sc, h0, h1, lam) for lam in lambdas]
\end{lstlisting}

\textbf{Dynamical structure factor \(S(q,\omega)\)} (section 6), from the
site-resolved correlators and a Fourier transform,
\(S(q,\omega)=\frac1n\sum_{ij}e^{iq(i-j)}S_{ij}(\omega)\):

\begin{lstlisting}
es = np.linspace(-0.5, 3, 200)
q = np.pi
Sqw = 0
for i in range(n):
    for j in range(n):
        x, y = sc.get_dynamical_correlator(submode="KPM", es=es, delta=0.1,
                                           name=(sc.Sz[i], sc.Sz[j]))
        Sqw = Sqw + np.exp(1j*q*(i-j))*y/n
\end{lstlisting}

\textbf{Extrapolation to the thermodynamic limit} (section 15), here of the
energy per site computed on several lengths \texttt{Ls}:

\begin{lstlisting}
from dmrgpy import extrapolate
e_inf = extrapolate.size_extrapolation(Ls, e_per_site, n=1)
\end{lstlisting}

\section{STM/Kondo tunneling spectra (third-order perturbation theory)}

In this section we compute the differential conductance \(dI/dV\) measured
by an STM tip above a magnetic atom or a spin chain on a surface. The
electrons tunnel from the tip to the sample, and on the way they exchange
spin and energy with the spins. We follow the perturbation theory of
Ternes, New J. Phys. 17, 063016 (2015), arXiv:1505.04430, to third order
in the coupling. The tip couples to one site of the chain. Here the chain
is a single spin-1/2 in a magnetic field, with \(H\) in eV:

\begin{lstlisting}
import numpy as np
from dmrgpy import spinchain
muB, g, B = 5.7883818066e-5, 2.0, 10.0    # eV/T, g-factor, field in T
sc = spinchain.Spin_Chain(["S=1/2"])
sc.set_hamiltonian(g*muB*B*sc.Sz[0])
eV = np.linspace(-4e-3, 4e-3, 161)        # bias in eV
eV, dIdV = sc.get_kondo_spectrum(eV, site=0, Jrho_s=-0.05, U=0.25, T=1.0)
\end{lstlisting}

\textbf{Second order} (\texttt{order=2}) is the Fermi golden rule for spin-flip and
elastic tunneling,

\[\frac{dI}{dV}(eV)\propto\sum_{i,f}p_i\Big[\tfrac12|\langle f|S_-|i\rangle|^2+\tfrac12|\langle f|S_+|i\rangle|^2+|\langle f|S_z|i\rangle|^2\Big]\,\Theta(eV-\epsilon_{if})+4U^2,\]

summed over both tunneling directions. Here \(p_i\) is the Boltzmann weight
of eigenstate \(i\), \(\epsilon_{if}=E_f-E_i\), and \(\Theta\) a step broadened
by temperature. Each excitation of the spins gives a step in \(dI/dV\) at
\(eV=\pm\epsilon_{if}\). This is inelastic tunneling spectroscopy (IETS),
and the step positions measure the spin excitation energies, for example
the Zeeman energy.

\textbf{Third order} (\texttt{order=3}, the default) adds two terms. Both sum over
every eigenstate \(m\) as a virtual intermediate state. The Kondo term
involves three spin matrix elements and a logarithmic function
\(F(\epsilon,T)\). It gives a peak at zero bias, which splits into two
peaks at the Zeeman steps in a field. The potential-interference term,
present when \texttt{U} is not zero, makes the spectrum asymmetric in bias. The
second-order and Kondo terms are even in \(eV\), and the potential term is
odd in \(eV\).

At the parameters of the paper (\(S=1/2\), \(B=0\), \(T=1\) K,
\(J\rho_s=-0.05\), \(\omega_0=20\) meV), the zero-bias peak divided by \(2\pi\)
is 1.13 for \(U=0\) and 1.39 for \(U=0.25\), as in the paper's figures. In a
field the code departs from the paper in one place: the exchange diagram
of the Kondo term has its logarithm at \(F(eV-(\epsilon_f-\epsilon_m))\),
which is what an exact second-order T-matrix gives, and not at the
argument of the paper's eq. 25. The two agree at zero field for \(S=1/2\)
and at zero bias. In the cases tested with a field or anisotropy, they
differ by 5 to 20 per cent of the third-order term. The keywords are:

\begin{itemize}
\tightlist
\item
  \texttt{site}: the site under the tip.
\item
  \texttt{Jrho\_\allowbreak{}s}: the dimensionless Kondo coupling \(J\rho_s\), in the sign
  convention of the paper (which uses \(-0.05\)).
\item
  \texttt{U}: the ratio of potential scattering to spin scattering.
\item
  \texttt{T}: the temperature in kelvin. \texttt{kB} (default in eV/K) converts it to
  the energy unit of \(H\).
\item
  \texttt{omega0}, \texttt{Gamma0}: the band cutoff and the lifetime broadening of the
  Kondo function \(F\).
\item
  \texttt{T0}: the tunneling strength. It only sets the overall scale.
\item
  \texttt{order}: 2 or 3.
\end{itemize}

\textbf{ED and DMRG.} \texttt{mode="ED"} (the default) diagonalizes the full
Hamiltonian, since every eigenstate enters as a virtual state. It works
at any temperature, on small chains. \texttt{mode="DMRG"}
works at \(T=0\) only and never needs excited states. The second-order and
potential terms come from the dynamical correlator of section 6, and the
Kondo term from a real-time evolution of a three-point function. It runs
on \texttt{itensor\_\allowbreak{}version=3} and \texttt{"python"}, on chains of at least 3 sites.
Here \texttt{sc} is a 3-site chain with couplings of order \(10^{-3}\) eV:

\begin{lstlisting}
es = np.linspace(-3e-3, 3e-3, 800)
eV, dIdV = sc.get_kondo_spectrum(eV, Jrho_s=-0.05, U=0.0, T=0.0, order=3,
               omega0=2e-3, Gamma0=2e-3, mode="DMRG", submode="KPM",
               delta=2e-5, es=es,
               dt2=150.0, n_t2_half=20, dtau=150.0, n_tau_half=20)
\end{lstlisting}

These keywords have no default and must be chosen for the problem:

\begin{itemize}
\tightlist
\item
  \texttt{es}: the frequency grid of the dynamical correlator. For \texttt{order=2} it
  must cover the transitions below \(\max|eV|\). With \texttt{U} not zero it must
  cover the whole spin excitation spectrum of the site, plus a few
  \texttt{delta}. The grid may be non-uniform.
\item
  \texttt{delta}, \texttt{submode}: the broadening and the method of the dynamical
  correlator.
\item
  \texttt{dt2}, \texttt{n\_\allowbreak{}t2\_\allowbreak{}half}, \texttt{dtau}, \texttt{n\_\allowbreak{}tau\_\allowbreak{}half}: the two time grids of the
  Kondo term. They must resolve the time scales \(1/\omega_0\) and
  \(1/\Gamma_0\), so the default \(\omega_0\) and \(\Gamma_0\) need very long
  grids. Too coarse a grid gives a wrong result without any error, so
  compare with \texttt{mode="ED"} on a small chain first.
\item
  \texttt{n\_\allowbreak{}gs}: the number of degenerate ground states. With a degenerate
  ground state, \texttt{mode="ED"} averages over the multiplet, while DMRG
  returns one member. \texttt{n\_\allowbreak{}gs=g} makes DMRG average over \texttt{g} states too.
\end{itemize}

See \texttt{examples/kondo/kondo\_\allowbreak{}third\_\allowbreak{}order\_\allowbreak{}dmrg\_\allowbreak{}VS\_\allowbreak{}ED}. The tip couples to one
site only; several sites with independent couplings are not implemented.

\subsection{Orbital-resolved IETS of a magnetic atom}

\texttt{dmrgpy.\allowbreak{}atom} describes a single atom with five \(d\) orbitals instead of a
chain. \texttt{generate\_\allowbreak{}atom} builds a \texttt{Spinful\_\allowbreak{}Fermionic\_\allowbreak{}Chain} whose sites are
the orbitals, with a crystal field \texttt{tij}, spin-orbit coupling \texttt{soc}, the
interactions \texttt{U} and \texttt{J}, a magnetic field \texttt{B} acting as
\(2\mathbf S+\mathbf L\), and \texttt{Ne} electrons. Two IETS signals are
available:

\begin{lstlisting}
from dmrgpy import atom
orbs = ["dxy", "dyz", "dz2", "dxz", "dx2y2"]
tij = np.diag([0.0, 0.05, 0.6, 0.05, 0.6])           # crystal field, eV
fc = atom.generate_atom(orbs=orbs, tij=tij, Ne=2, soc=0.03, U=4., J=0.5)
es = np.linspace(0., 0.1, 301)
x, y = atom.get_spinflip(fc, es=es, iorb=2, delta=1e-3)
x, y = atom.get_orbital_cotunneling(fc, es=es, iorb=2, delta=1e-3)
\end{lstlisting}

\begin{itemize}
\tightlist
\item
  \texttt{get\_\allowbreak{}spinflip}: the spin-flip signal, \(\sum_aS_{aa}(\omega)\) built from
  \(S^a-\langle S^a\rangle\) on orbital \texttt{iorb}.
\item
  \texttt{get\_\allowbreak{}orbital\_\allowbreak{}cotunneling}: the orbital cotunneling signal, from
  \(c^\dagger_{\texttt{iorb}\,\sigma}c_{j\sigma'}\) summed over the other
  orbitals \(j\) and both spins.
\end{itemize}

\texttt{iorb} is the orbital the tip couples to, for example \(d_{z^2}\) for a tip
on top of the atom. With a crystal field, different orbitals give
different weights and different peak positions. Both functions use ED.
The low multiplet of an atom is often nearly degenerate, so the remarks
of section 6 on \texttt{dex} and \texttt{T} apply here. See
\texttt{examples/kondo/atom\_\allowbreak{}iets\_\allowbreak{}orbital\_\allowbreak{}resolved}.

\section{Infinite chains (iDMRG)}

An infinite chain repeats a unit cell of \texttt{n\_\allowbreak{}uc} sites forever in both
directions. It describes the thermodynamic limit directly, with no edges
and no finite-size extrapolation. The state is a uniform matrix product
state, and the results are densities per site and correlators at any
distance.

\textbf{Building the Hamiltonian.} Each operator exists in three copies per
site \texttt{i} of the unit cell: \texttt{SzC{[}i{]}} in the central cell, \texttt{SzR{[}i{]}} in the
next cell and \texttt{SzL{[}i{]}} in the previous cell. A term is written once, and
it is repeated in every cell:

\begin{lstlisting}
from dmrgpy import infinitechain
ic = infinitechain.Infinite_Spin_Chain(["1/2"])          # n_uc = 1
h = ic.SxC[0]*ic.SxR[0] + ic.SyC[0]*ic.SyR[0] + ic.SzC[0]*ic.SzR[0]
ic.set_hamiltonian(h)
e = ic.gs_energy()      # energy per site
\end{lstlisting}

A two-site cell describes for example a dimerized chain:

\begin{lstlisting}
ic = infinitechain.Infinite_Spin_Chain(["1/2", "1/2"])
h = (1.0*(ic.SxC[0]*ic.SxC[1] + ic.SyC[0]*ic.SyC[1] + ic.SzC[0]*ic.SzC[1])
     + 0.4*(ic.SxC[1]*ic.SxR[0] + ic.SyC[1]*ic.SyR[0] + ic.SzC[1]*ic.SzR[0]))
ic.set_hamiltonian(h)
\end{lstlisting}

For longer couplings, \texttt{ic.\allowbreak{}get\_\allowbreak{}operator(name,\ i,\ group=c)} gives site \texttt{i}
of the cell at distance \texttt{c}, so \texttt{c=-1,0,1} are \texttt{L}, \texttt{C}, \texttt{R}. For example
a J1-J2 chain on a one-site cell:

\begin{lstlisting}
h = 0
for op in ("Sx", "Sy", "Sz"):
    o0 = ic.get_operator(op, 0)
    h = h + o0*ic.get_operator(op, 0, group=1)        # J1
    h = h + 0.4*o0*ic.get_operator(op, 0, group=2)    # J2
\end{lstlisting}

At \(J_2=0.4\) this chain is dimerized, so its ground state has a period of
two sites. A one-site cell cannot hold it and the solver does not
converge. Use the same couplings on a two-site cell for this phase.

Fermionic chains use \texttt{Infinite\_\allowbreak{}Many\_\allowbreak{}Body\_\allowbreak{}Chain} with a list of site
codes: \texttt{0} for a spinless fermion (\texttt{C}, \texttt{Cdag}, \texttt{N}) and \texttt{1} for a
spinful site (\texttt{Cup}, \texttt{Cdagup}, \texttt{Cdn}, \texttt{Cdagdn}, \texttt{Nup}, \texttt{Ndn}). The
Jordan-Wigner string is added automatically, also for hoppings that skip
sites. A term with an odd number of fermion operators raises an error.

\textbf{Two solvers.} \texttt{ic.\allowbreak{}gs\_\allowbreak{}method} selects the algorithm:

\begin{itemize}
\tightlist
\item
  \texttt{"vumps"} (the default): variational uniform MPS (arXiv:1701.07035).
  It finds the best state of bond dimension \texttt{maxm} directly in the
  thermodynamic limit. It works for any unit cell and any range of
  coupling.
\item
  \texttt{"idmrg"}: infinite DMRG, which grows a finite chain from the center
  until the energy per site converges. Only \texttt{n\_\allowbreak{}uc} of 1 or 2.
\end{itemize}

Both run on \texttt{itensor\_\allowbreak{}version="python"} and \texttt{3}. \texttt{itensor\_\allowbreak{}version=2} and
\texttt{"julia\_\allowbreak{}live"} raise an error. The keywords are:

\begin{itemize}
\tightlist
\item
  \texttt{ic.\allowbreak{}maxm}, \texttt{ic.\allowbreak{}cutoff}: the bond dimension (default 30) and the
  truncation cutoff. Increase \texttt{maxm} until the results stop changing.
\item
  \texttt{ic.\allowbreak{}maxiter}, \texttt{ic.\allowbreak{}etol}: the maximal number of iterations and the
  energy tolerance.
\item
  \texttt{ic.\allowbreak{}vumps\_\allowbreak{}nrestarts}: the number of random starts of VUMPS (default 4).
\item
  \texttt{ic.\allowbreak{}noise}, \texttt{ic.\allowbreak{}noise\_\allowbreak{}iters}: for iDMRG. A particle-conserving model has
  the empty and the full state as exact eigenstates, and iDMRG can get
  stuck in them. The noise (default \(10^{-4}\)) breaks this, and is applied
  only while the state is a product state.
\end{itemize}

After the solve, \texttt{ic.\allowbreak{}converged} says whether the tolerance was reached.
If it was not, \texttt{gs\_\allowbreak{}energy()} also gives a \texttt{RuntimeWarning} with the
reason. VUMPS starts from a random state, so on a hard model
call \texttt{gs\_\allowbreak{}energy()} a few times and keep the lowest energy. A simple
product state, such as the Neel state, gives an upper bound to compare
with. For a gapless
model the convergence of iDMRG is slow, so \texttt{converged} can be \texttt{False}
while the energy is already accurate to several digits. Entanglement
entropies are not available for infinite chains.

\textbf{Static correlators.}

\begin{lstlisting}
ic.vev("Sz", 0)                    # <Sz> on site 0 of the cell
ic.correlator("Sz", 0, "Sz", r)    # <Sz_0 Sz_r>, r in sites, r >= 0
ic.correlator("Cdag", 0, "C", r)   # fermionic chain, with the string
\end{lstlisting}

They work with both solvers and both backends. A pair with an odd number
of fermion operators raises an error. A good check of \texttt{maxm} needs no
reference value: the sum of the bond correlators of one unit cell must be
equal to \texttt{n\_\allowbreak{}uc} times the energy per site.

\textbf{Excitations.} In an infinite chain the excitations form bands \(E(k)\).
We use the quasiparticle ansatz: one tensor \(B\) inserted on top of the
ground state, in a plane wave of momentum \(k\). This gives the dispersion
of the lowest modes, as measured by inelastic neutron scattering:

\begin{lstlisting}
ic.excitation_energies(k, n=1)   # n lowest energies at momentum k
ic.excitation_gap()              # minimum over k
\end{lstlisting}

\(k\) is in radians per unit cell. It needs \texttt{gs\_\allowbreak{}method="vumps"}, \texttt{n\_\allowbreak{}uc} of
1 or 2, and couplings to the neighboring cell only.

\textbf{Dynamical structure factor.} Each quasiparticle branch \(a\) contributes
a delta peak to \(S(k,\omega)\) with weight
\(w_a=|\langle k,a|O_k|\mathrm{GS}\rangle|^2\):

\[S(k,\omega)=\sum_aw_a\,\delta(\omega-E_a(k)).\]

\begin{lstlisting}
e, w = ic.spectral_weights("Sz", k, n=2)
e, w, total = ic.spectral_weights("Sz", k, n=2, return_total=True)
ks, es, S = ic.dynamical_structure_factor("Sz", delta=0.05)  # map in (k, w)
\end{lstlisting}

The peaks are exact in momentum and energy. They do not contain the
continuum of two or more particles. \texttt{total} is the static structure
factor \(\sum_re^{ikr}(\langle O_0O_r\rangle-\langle O\rangle^2)\), so
\texttt{w.\allowbreak{}sum()/total} is the fraction of the weight in the computed branches.
When it is close to 1, a single-mode picture is valid at that \(k\). In
\texttt{dynamical\_\allowbreak{}structure\_\allowbreak{}factor}, \texttt{delta} is a Lorentzian broadening for
plotting. These two methods need \texttt{itensor\_\allowbreak{}version="python"} and
\texttt{gs\_\allowbreak{}method="vumps"}, and a parity-even operator. See
\texttt{examples/idmrg/dynamical\_\allowbreak{}structure\_\allowbreak{}factor\_\allowbreak{}tfim}.

\textbf{Local gap estimate.} \texttt{ic.\allowbreak{}local\_\allowbreak{}excitation\_\allowbreak{}gap()} takes the converged
two-site block of iDMRG and returns the gap between its two lowest
states. It is cheap, but less accurate than \texttt{excitation\_\allowbreak{}gap()} (10 per
cent too high on the XX chain). On fermionic models it can be a charge
excitation and shifts with a uniform chemical potential. Use it only as a
rough check. It needs \texttt{gs\_\allowbreak{}method="idmrg"}. \texttt{window=w}, with
\texttt{itensor\_\allowbreak{}version="python"} and \texttt{n\_\allowbreak{}uc=1}, adds \texttt{w} sites on each side of
the block and improves the estimate.

\textbf{Dynamical correlators.} Two methods compute
\(\langle O_i(t)O_j\rangle\) and its spectrum in an infinite chain:

\begin{lstlisting}
es, ys = ic.kpm_finite("Sz", 0, "Sz", 0, n_window=16,
             window_chain_kwargs=dict(maxm=30, nsweeps=15),
             delta=0.3, es=np.linspace(-1, 5, 200))
ic.gs_method = "idmrg"
ks, es, Skw = ic.td_dynamical_correlator("Sz", 0, "Sz", n_window=14,
             dt=0.05, nt=200, maxdim=60, x_values=range(-6, 7),
             ks=np.linspace(-np.pi, np.pi, 41), delta=0.1)
\end{lstlisting}

\begin{itemize}
\tightlist
\item
  \texttt{kpm\_\allowbreak{}finite}: the KPM correlator of section 6 on a finite open window of
  \texttt{n\_\allowbreak{}window} unit cells. It has finite-size and edge effects, so converge
  it in \texttt{n\_\allowbreak{}window}. A small \texttt{delta} needs many moments, and then the
  edges matter even for a long window. The window always runs on
  \texttt{itensor\_\allowbreak{}version="python"}.
\item
  \texttt{td\_\allowbreak{}dynamical\_\allowbreak{}correlator}: real-time evolution of a window whose two
  ends are attached to the converged infinite environment
  (arXiv:1804.09163), so it has no edges. One evolution gives every
  distance \texttt{x} and every momentum \texttt{k}. \texttt{n\_\allowbreak{}window} and \texttt{x\_\allowbreak{}values} must be
  converged separately. It needs \texttt{gs\_\allowbreak{}method="idmrg"}. \texttt{connected=True}
  (default) subtracts \(\langle O_i\rangle\langle O_j\rangle\). It returns
  the one-sided Fourier transform, so take the real part of \texttt{Skw} for the
  spectral function.
\end{itemize}

See \texttt{examples/idmrg/td\_\allowbreak{}dynamical\_\allowbreak{}correlator} for both.

\textbf{Lower-level tools.} These act on the converged state of
\texttt{itensor\_\allowbreak{}version="python"} (\texttt{ic.\allowbreak{}\_\allowbreak{}result} for iDMRG, \texttt{ic.\allowbreak{}\_\allowbreak{}vumps\_\allowbreak{}result}
for VUMPS) and have no method on the chain:

\begin{itemize}
\tightlist
\item
  \texttt{pyitensor.\allowbreak{}idmrg.\allowbreak{}apply\_\allowbreak{}mpo} and \texttt{pyitensor.\allowbreak{}vumps.\allowbreak{}apply\_\allowbreak{}mpo}: apply a
  bounded periodic operator, for example a product of one-site operators
  or a gate, and truncate. Not for a Hamiltonian, which is extensive.
\item
  \texttt{pyitensor.\allowbreak{}idmrg.\allowbreak{}imps\_\allowbreak{}overlap}: the overlap per site of two infinite
  states, 1 in magnitude for the same state.
\item
  \texttt{pyitensor.\allowbreak{}idmrg.\allowbreak{}imps\_\allowbreak{}sum} and \texttt{pyitensor.\allowbreak{}vumps.\allowbreak{}imps\_\allowbreak{}sum}: the direct
  sum of two states. Two normalized ground states give a cat state, which
  this cannot represent, and raise an error.
\end{itemize}

See \texttt{examples/idmrg/vumps\_\allowbreak{}apply\_\allowbreak{}mpo}, \texttt{imps\_\allowbreak{}overlap} and \texttt{vumps\_\allowbreak{}imps\_\allowbreak{}sum}.

\section{Running the pure-Python backend on a GPU}

The \texttt{itensor\_\allowbreak{}version="python"} backend can keep its tensors on a GPU. It
needs \texttt{jax} with CUDA support. The switch is global and is set before
building a chain:

\begin{lstlisting}
from dmrgpy.pyitensor import backend
backend.set_backend("jax")       # "numpy", the default, goes back to the CPU
print(backend.device_info())     # for example "jax: cuda:0"
\end{lstlisting}

The rest of the script does not change, and the results agree with the
CPU ones to about \(10^{-11}\). A GPU helps only when the bond dimension is
large: below about 120 it is slower than the CPU, and at 240 it is about
5 times faster. So it pays for real-time evolution, where the bond
dimension grows, and rarely for a 1D ground state. Infinite chains and
non-Hermitian DMRG run but do not get faster. For a script that does one
calculation and exits, \texttt{backend.\allowbreak{}set\_\allowbreak{}pad\_\allowbreak{}bonds(maxm)} fixes all tensor
shapes so that each kernel is compiled only once. With padding on, the
default \texttt{backend.\allowbreak{}set\_\allowbreak{}jit("auto")} also fuses the kernels. For a KPM
correlator,
set \texttt{kpmmaxm} equal to \texttt{maxm}. See \texttt{docs/gpu\_\allowbreak{}cpu\_\allowbreak{}performance.\allowbreak{}md} for the
measurements.

\section{Performance: BLAS threads}

DMRG makes many small matrix operations, and on small matrices several
BLAS threads are slower than one. It matters most when the machine is
shared, for example on a cluster node or with several runs in parallel,
where a calculation can become 3 to 17 times slower. Pin one thread
before Python imports numpy:

\begin{lstlisting}
MKL_NUM_THREADS=1 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python3 myscript.py
\end{lstlisting}

Inside a script, \texttt{blasthreads.\allowbreak{}limit(1)} does the same for one block. It
needs the package \texttt{threadpoolctl}, and without it does nothing and gives a
warning:

\begin{lstlisting}
from dmrgpy import blasthreads
with blasthreads.limit(1):
    e0 = sc.gs_energy()
\end{lstlisting}

dmrgpy never changes the number of threads by itself.
